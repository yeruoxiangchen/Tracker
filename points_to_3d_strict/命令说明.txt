Points-to-3D strict reproduction commands
日期：2026-06-27

目标：

严格按 /home/zjr/Tracker/2603.18782v1.pdf 的 sparse structure inpainting 形式实现最小复现分支。

本目录不使用之前 trellis_point_prior_mv 里额外探索过的：

  - SparsePointPriorCond token condition
  - anti-overfill loss
  - ranking loss
  - base-guided selection
  - sparse post-filter
  - stock union
  - hard rerank

严格版只做论文核心机制：

  1. visible point prior -> TRELLIS sparse VAE encoder -> q_vis
  2. visible mask -> latent mask m_s
  3. q_t = (1-t) q_gt + t noise，按 TRELLIS flow matching 公式实现
  4. q_comb(t) = m_s * q_vis + (1 - m_s) * q_t
  5. flow 输入从 C_s 通道改成 C_s + C_m 通道：
       x_inp = Concat[q_comb(t), m_s]
  6. 使用原 TRELLIS image condition；第一轮 overfit 先用 first view，机制通过后再打开多视图 concat
  7. loss 只使用 CFM velocity MSE，不加 ranking / anti-overfill / filter / union 等工程 loss
     第一轮诊断默认 unknown 为主、known 轻权重：
       loss = unknown_mse + 0.1 * known_mse
     这是为了匹配推理时 known region 被 q_vis clamp 的行为。
  8. 推理支持两段：
       structural inpainting stage: Concat[m_s*q_vis+(1-m_s)*q_t, m_s]
       boundary refinement stage:  Concat[q_t, all-ones mask]
     第一轮 overfit 关闭 boundary refinement，因为当前训练未加入 all-ones mask 分布。

六、快速摘要

```bash
/home/zjr/anaconda3/envs/reconviagen/bin/python - <<'PY'
import json
from pathlib import Path

runs = [
    '/home/zjr/Tracker/points_to_3d_strict/outputs/points_to_3d_strict_overfit1_s500_cfg1_noboundary/eval/report.json',
    '/home/zjr/Tracker/points_to_3d_strict/outputs/points_to_3d_strict_train64_s1000_val32_cfg1_noboundary/eval/report.json',
]

for rp in runs:
    p = Path(rp)
    if not p.exists():
        continue
    d = json.loads(p.read_text())
    print('\\n====', p)
    for name, row in d['summary']['by_source_decode'].items():
        if not name.endswith('/topk_target_unique'):
            continue
        if not (
            name.startswith('q_gt/')
            or name.startswith('q_vis/')
            or name.startswith('q_splice/')
            or name.startswith('q_pred/')
            or name.startswith('teacher_forced_raw')
            or name.startswith('teacher_forced_hard')
        ):
            continue
        print(
            name,
            'iou=', row.get('decoded_vs_target_iou_mean'),
            'recall=', row.get('decoded_vs_target_target_recall_mean'),
            'comp=', row.get('decoded_component_count_mean'),
            'largest=', row.get('decoded_largest_component_ratio_mean'),
            'unknown_l1=', row.get('q_pred_unknown_vs_q_gt_l1_mean')
                or row.get('teacher_forced_raw_unknown_vs_q_gt_l1_mean')
                or row.get('teacher_forced_hard_unknown_vs_q_gt_l1_mean'),
        )
PY
```

## 十二、2026-06-29 train512 high-t bridge curriculum 命令

### 12.0 背景和原则

上一轮结论：

```text
1. phase1 [0,0.75] 已经能在 q_splice_t 0.75/0.50/0.25 上有效 inpaint；
2. phase2 [0,1] step1000/2000 保留了 q_splice_t low/mid-t 能力；
3. phase2 noise START_T=1.0 在 train128 / val128 都低于 q_vis；
4. phase2 step3000/4000 退化，不作为候选；
5. noise START_T<1 当前是 off-schedule stress test，不作为主指标。
```

因此下一轮不要从 `phase2 last.ckpt` 继续，也不要直接再训 `[0,1]`。推荐从 phase1 checkpoint 重新开更缓的 high-t bridge：

```text
phase2a: [0,0.85], LR=5e-6, 1000 steps
phase2b: [0,0.95], LR=5e-6, 1000 steps, resume phase2a
phase2c: [0,1.00], LR=2e-6, 1000 steps, resume phase2b
```

每个阶段结束后都必须同时评估：

```text
q_splice_t START_T=0.90/0.75/0.50/0.25
noise START_T=1.0
```

判断顺序：

```text
1. 先看 q_splice_t 是否保持 phase1 能力；
2. 再看 q_splice_t 0.90 是否提高；
3. 最后看 noise START_T=1.0 是否超过 q_vis；
4. 只有 sparse 明显超过 q_vis 后再跑 mesh。
```

## 十四、2026-06-30 view-gated multiview adapter

### 14.1 背景

第十三节 `IMAGE_MAX_VIEWS=4 + IMAGE_COND_AGGREGATION=mean` 的结论是：

```text
1. mean 聚合接口能跑，但收益极小；
2. full-flow fp16 在 mv4 mean 下 200-step smoke 会 NaN；
3. 下一步不应继续 mean 聚合长训，而应改成真正的 view-level fusion。
```

本节新增：

```text
IMAGE_COND_AGGREGATION=view_gated
TRAIN_CONDITION_ADAPTER_ONLY=1
```

`view_gated` 做法：

```text
输入:  [B, V, T, C] per-view image tokens
输出:  [B, T, C] fused tokens
初始化: 每个 token 对 V 个 view 做 uniform average，等价 mean
训练:  先只训练 ViewGatedConditionAdapter，冻结 strict sparse flow
```

## 二十八、projection grid direct-to-G_inp input

### 28.0 代码改动说明

本轮新增的是“projection grid 直接进入 G_inp input”的路径，不再只把投影信息放在 condition adapter 里。

新增开关：

```text
STRICT_INPUT_PROJECTION_GRID=1
STRICT_INPUT_PROJECTION_CHANNELS=6
```

含义：

```text
默认关闭：
  G_inp 输入仍然是 Concat[q_comb, m_s]。

打开后：
  G_inp 输入变成 Concat[q_comb, m_s, projection_grid_features]。

STRICT_INPUT_PROJECTION_CHANNELS=3:
  visible_ratio / support_ratio / support_over_visible。

STRICT_INPUT_PROJECTION_CHANNELS=6:
  visible_ratio / support_ratio / support_over_visible /
  inv_depth_mean / inv_depth_max / selected_cell_mask。
  当前 direct-input 模式下 selected_cell_mask 由 max_projection_tokens=0 构造，因此初始为 0；
  主要使用前 5 个连续投影几何通道。
```

关键实现：

```text
points_to_3d_strict/strict_core.py
  strict_input_projection_channel_count()
  build_strict_input_projection_features()
  build_q_comb_t(..., extra_inputs=...)
  sample_points_to_3d_strict(..., extra_inputs=...)
  load_strict_checkpoint() 支持 shape-expanded load：
    旧 input_layer 权重复制到旧通道；
    新 projection 通道 zero-init。

points_to_3d_strict/train_strict_inpaint.py
  训练时扩展 G_inp input layer；
  每个 batch 构建 projection grid extra inputs；
  训练日志写入 strict_input_projection_*。

points_to_3d_strict/eval_strict_inpaint.py
  eval / teacher-forced 使用同一 extra inputs。

points_to_3d_strict/eval_strict_mesh.py
  mesh eval 使用同一 extra inputs。

points_to_3d_strict/run_strict_points_to_3d.sh
  透传 STRICT_INPUT_PROJECTION_GRID / STRICT_INPUT_PROJECTION_CHANNELS。
```

## 34. B1：zero-init block-wise global modulation

### 34.0 本节新增/修改代码

本节实现的是路线 B1：

```text
pooled(q_vis, m_s, projection_grid) -> zero-init block-wise global bias/FiLM
```

当前先用 `bias` 模式、最后 4 个 sparse-flow block。新 adapter 的 head 全部 zero-init，因此刚注入时应当等价于原 b1 baseline；只有显式训练时才改变 block 输出。

代码改动：

```text
points_to_3d_strict/strict_core.py
  新增 BlockwiseGlobalModulationAdapter
  新增 BlockwiseGlobalModulatedBlock
  新增 inject_flow_blockwise_global_modulation()
  新增 set_flow_blockwise_global_modulation_trainable()
  新增 build_blockwise_global_modulation_context()
  load_strict_checkpoint 支持 wrapped block key remap

points_to_3d_strict/train_strict_inpaint.py
  新增 --train_blockwise_global_modulation
  新增 --blockwise_global_target_blocks / hidden_dim / mode
  训练时只解冻 block-wise global adapter
  每个 batch 构造 pooled q_vis/m_s/projection context

points_to_3d_strict/eval_strict_inpaint.py
  新增 --blockwise_global_modulation
  eval 时支持注入同一 adapter 并加载 checkpoint

points_to_3d_strict/eval_strict_mesh.py
  mesh eval 同步支持 block-wise global modulation

points_to_3d_strict/run_strict_points_to_3d.sh
  新增 TRAIN_BLOCKWISE_GLOBAL_MODULATION
  新增 BLOCKWISE_GLOBAL_MODULATION
  新增 BLOCKWISE_GLOBAL_TARGET_BLOCKS / HIDDEN_DIM / MODE
```

## 35. B2：sparse-cell / token-wise projection condition



```text

  noise_t1 topk IoU +0.003 到 +0.005；

  unknown L1 不恶化；
  q_splice_t0.90 不低于 b1。
```
