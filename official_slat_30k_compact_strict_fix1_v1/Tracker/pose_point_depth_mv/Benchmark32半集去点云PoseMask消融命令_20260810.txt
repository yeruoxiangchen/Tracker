Benchmark32 半集去点云 Pose+Mask 消融命令（2026-08-10）
=========================================================

实验问题
--------
A（基线）：复用现有 M9 point+mask model inputs，在固定同一 16 对象上重放。
B（消融）：不读取 P_W/点置信度，只用相机 pose、K、前景 mask 构造 runtime-O。

两组固定复用相同的 8 视角、RGB、mask、DINO、mixed no-VGGT SS/SLat
checkpoint、EMA、CFG5、25 steps、seed42 和对象排序位置。A 必须重放，不能直接
截取原 M9 的 32 对象 Mesh，因为推理噪声还依赖对象位置。B 的 Mesh 不直接与原 O 标签比较，
而是先按 O_posemask -> W -> O_reference 转回原 Benchmark32 标签坐标。

这是 Benchmark32 development 消融，formal=false，不触碰 Holdout64，也不训练模型。

P1：先在前台构建固定 16/32 的 Pose+Mask runtime-O（CPU）
---------------------------------------------------------
这一步按 sha256("20260810|object_key") 升序固定抽 16 个对象；不会读取 P_W。
若 P1 已完成，一键后台脚本会直接复用。

set +e
set +u
set +o pipefail
(
  set -euo pipefail
  cd /home/zjr/Tracker
  PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
  ROOT=/data/zjr/omni_real_video500_download_20260804_v2
  EXP=/data/zjr/native_no_vggt_pose_mask_benchmark16_20260810_v1
  OUT=${EXP}/P1_pose_mask_runtime16_v1
  RESUME=()
  if [ ! -s "${OUT}/runtime_input_manifest.json" ] && [ -e "${OUT}" ]; then
    RESUME=(--resume)
  fi
  if [ ! -s "${OUT}/runtime_input_manifest.json" ]; then
    "${PY}" -u -m pose_point_depth_mv.dataset_tools.prepare_omni_real_pose_mask_runtime_inputs \
      --raw_cache_report "${ROOT}/D8_benchmark32_raw_cache_v1/raw_cache_report.json" \
      --reference_runtime_manifest "${ROOT}/D9_benchmark32_runtime_o_v2/runtime_input_manifest.json" \
      --output_dir "${OUT}" \
      --subset_count 16 --subset_seed 20260810 \
      --selected_view_count 8 \
      "${RESUME[@]}"
  fi
  "${PY}" - "${OUT}/runtime_input_manifest.json" <<'PY'
import json, sys
p=json.load(open(sys.argv[1], encoding="utf-8"))
assert p["passed"] is True and p["completed_object_count"]==16
assert p["point_cloud_consumed"] is False
assert all(x["point_cloud_fields_read"]==[] for x in p["objects"])
assert all(all(x["external_visible_equivalence"].values()) for x in p["objects"])
print({"passed":True,"objects":16,"point_cloud_consumed":False,
       "selected":[x["object_key"] for x in p["objects"]]})
PY
)
P1_RC=$?
echo "P1_RC=${P1_RC}; current terminal remains open"

C1-C6：运行冻结的剩余16例，并生成统一采样的完整Benchmark32六方法报告
------------------------------------------------------------------------
这不是重新随机抽16例。它严格取P1同一sha256排序的第17--32名，即
`subset_offset=16, subset_count=16`，与首轮16例无交集且两者并集恰好为Benchmark32。

C1-C5复用上面的同一流程，在新目录中完成剩余16例Point+Mask/Pose+Mask同噪声推理；
C6再把首轮P5和本轮C5合并，并将已有ReconViaGen、Pixal3D和两个Full参考的Mesh全部按
PoseMask协议的同一20k表面采样种子重新量化。外部base无需重新推理。

以下默认使用GPU4；若GPU4忙，只修改`POSE_MASK_ABLATION_GPU`：
