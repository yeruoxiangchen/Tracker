# Direct-SLAT V5.1：LoRA/support 分支预算 + 常显存终点 rollout 排序
# 2026-07-29
#
# V4 Fresh Blind32 的结论是“弱正向、正式门未通过”，不是程序失败：
# - Chamfer mean +0.00013156，median +0.00004072，win 56.25%
# - bootstrap mean 95% CI 下界 -0.00003437，formal_pass=false
#
# V5 保留两个可检验机制：
# 1. 将部署 Full residual 拆成 LoRA(stock->LoRA) 与
#    support-increment(LoRA->joint Full)，分别做 stock-RMS 相对预算，
#    最后仍保留总 residual cap。
# 2. V4 的多步 endpoint 只拟合 target；V5 要求 Full x0 proxy loss 比
#    同状态 Stock x0 proxy loss 至少好一个固定 margin。
#
# 2026-07-29 zero-init 修正：
# - support 缺失、显式关闭或 support_scale=0 均直接走 exact Stock bypass；
# - V5 联合分支和 LoRA-only 分支同时做 straight-through zero-init anchor。
# 旧 V5 的 all_visited_v1 在确定性 horizon=8、大稀疏样本上同时保留八套
# joint Full + LoRA-only 图，双卡 DDP 的每个 rank 都超过单卡 24 GB。
# V5.1 仍生成完整 2/4/8-step 数值轨迹，但中间状态使用 no_grad+detach，
# 只在终点保留一套监督图；输出改为全新 v3，禁止把旧 V5 step40 当作同语义续训。
#
# 不变：
# - frozen corrected SS / physical encoder / native SLAT condition / mesh decoder；
# - post-CFG v2、smooth RMS、CFG active interval；
# - 897-object 先行，不直接启动 10k 模型长训。
#
# GPU：
# - smoke/评估 1 卡，训练 2 卡；本文件不会使用超过 2 张卡。
# - 与 Mixed10k 渲染合计不得超过项目 4-GPU 预算。

run_logged() {
  LOG_PATH=$1
  shift
  set +e
  "$@" 2>&1 | tee "${LOG_PATH}"
  COMMAND_RC=${PIPESTATUS[0]}
  printf '%s\n' "${COMMAND_RC}" > "${LOG_PATH}.exit_code"
  return "${COMMAND_RC}"
}
