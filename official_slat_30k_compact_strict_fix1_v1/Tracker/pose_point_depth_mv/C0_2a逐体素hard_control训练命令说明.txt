# C0.2a 逐体素 Hard-control Ranking 训练与测试命令
# 日期：2026-07-17
#
# 一、阶段目标
#
# 旧C0训练只在sample_score上做rank，在voxel_score上只做correct/control BCE；
# C0.1正式门却使用：
#
#   hard_margin[x] = correct_voxel_score[x]
#                  - max(control_voxel_score_k[x])
#
# C0.2a只修正这一处训练/评估目标错位。以下内容保持不变：
#
#   head结构与参数量
#   evidence schema和18个geometry通道
#   train16/fresh48对象划分
#   随机view subset协议
#   三类training controls
#   原sample BCE/rank、voxel BCE及其权重
#
# 本阶段不加入confidence weighting、不平衡2/4/8-view、不增加signed depth，
# 避免一次改变多个变量。C0.2a新损失为：
#
#   d_k[x] = correct[x] - control_k[x]
#
#   L_all = mean_k softplus((margin - d_k) / temperature) * temperature
#
#   L_smooth_hard = temperature *
#       log(1 + sum_k exp((margin - d_k) / temperature))
#
#   L_voxel_rank = L_all + hard_weight * L_smooth_hard
#
# L_all保证每个control持续有梯度；L_smooth_hard强调当前位置最难的control，
# 同时不会像裸max一样只给argmax分支梯度。正式评估仍使用exact max，不使用
# smooth近似。
#
# 二、预注册参数
#
#   --voxel_rank_weight 1.0
#   --voxel_rank_margin 0.25
#   --voxel_rank_temperature 0.10
#   --voxel_rank_hard_weight 0.5
#
# 旧命令未传--voxel_rank_weight时默认0，保持旧训练行为。
#
# 三、执行约定
#
# 1. 顺序执行V9.1 -> V9.2 -> V9.3 -> V9.4 -> V9.5 -> V9.6。
# 2. seed42 train16/fresh48配对通过后，才允许执行V9.7和V9.8。
# 3. 每个外层命令块最终exit 0，不会因为科学FAIL关闭当前终端。
# 4. 真实程序状态写入*.exit_code；科学判定写入*.decision_code。
# 5. 不覆盖已存在的不完整目录；遇到不完整目录记98并人工换名或检查。
# 6. 不使用--fail_on_decision。
# 7. fresh48已参与方案设计，只是开发集；即使通过也不能替代新的未查看holdout。
