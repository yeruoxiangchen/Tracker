日期：2026-07-19

======================================================================
一、当前模型与实验结构
======================================================================

C0.3（保持冻结）：

  per-view VGGT/Image visual patch
  + per-view pose/ray/depth geometry
  -> gaussian3局部容差（correct与全部control对称）
  -> frozen ViewCorrespondenceHead
  -> 16^3 voxel correspondence score

C1.0b（无训练，不加载Flow/decoder）：

  correct ranking
  reliability ranking
  pose-corruption ranking
  depth-corruption ranking
  visual-corruption ranking
  spatial-permutation ranking

  每个ranking都接收：
    correct policy的相同weight histogram
    相同active support
    相同nonzero count
    相同L1 mass
    相同top 5/10/20% voxel预算

  target仅用于最后的exact / surface-r1审计。

C1.1b（直接局部occupancy监督，仍不加载Flow/decoder）：

  M0_reliability：
    raw reliability -> linear occupancy probe

  M1_view_geometry：
    raw reliability
    + frozen C0 joint per-view token weighted mean
    + frozen C0 joint per-view token weighted std
    + fixed-support统计
    -> MLP occupancy probe

  M2_plus_correspondence：
    M1 base
    + histogram-matched correspondence weight residual branch
    -> occupancy logit

  M1和M2 base初始化完全相同，但参数和optimizer独立。
  训练只使用correct branch；pose/depth/visual corruption只用于因果评估。

八、C1.1b正式裁决
======================================================================

只有3 seed的Fresh和Holdout全部满足以下条件才进入C1.2：

  M2 correct balanced BCE < M1 correct balanced BCE
  M2 correct balanced BCE < M2 pose-corruption balanced BCE
  M2 correct balanced BCE < M2 depth-corruption balanced BCE
  M2 correct balanced BCE < M2 visual-corruption balanced BCE

每项均要求：

  object mean > 0
  object median > 0
  object win rate >= 0.65
  bootstrap 95% CI lower > 0
  2-view mean不反向

PASS：

  只允许进入frozen-base C1.2 causal occupancy adapter；
  仍不自动允许Flow LoRA。

FAIL：

  停止target occupancy方向；
  不继续增加probe容量或训练步数；
  C0保留为Pose/Depth/Visual correspondence质量审计器；
  reliability保留为独立通用几何支持基线。
