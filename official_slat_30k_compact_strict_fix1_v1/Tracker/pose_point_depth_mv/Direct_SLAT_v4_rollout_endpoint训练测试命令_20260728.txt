# Direct-SLAT V4 rollout-endpoint：897 数据训练与测试命令
# 2026-07-28
#
# 目标：
# - 不续训已停止的 V3/S7；V4 从 stock-equivalent zero-init 重新训练。
# - 保留 post-CFG v2，改用 smooth_rms_v2，避免 S7 的 detached hard-cap 饱和。
# - 训练时间点严格来自部署的 25-step / rescale_t=3 native schedule。
# - rollout 采用互斥抽样的 1/2/4-step truncated rollout，并监督每个 visited state。
# - 最后 visited state 增加 x0/target-SLAT endpoint proxy。
# - support 只在原生 CFG 区间 [0.5,1.0] 生效；区间外 Full 值严格等于 Stock。
#
# 决策顺序：
#   S0 CPU/CLI -> S1 单卡 14-step 分支 smoke -> S2 语义审计
#   -> S3 双卡 step100 -> S4 teacher 诊断 -> S5 same-noise Mesh utility
#   -> 只有 Mesh 没有退化，才批准 S6 续训到 step400。
#
# 科学解释：
# - S4 teacher-forced 只用于诊断和选 checkpoint，不是最终收益结论。
# - S5/S7 的 Full-vs-Stock Mesh 是主门；Pixal3D/SOTA 是后续 utility 比较。
# - wrong-support 不再作为必须通过的主 gate，但仍记录 stock-reversion 诊断。
#
# GPU 上限：
# - S1/S4/S5：1 GPU；S3/S6：2 GPU。
# - 本命令不会使用超过 2 张卡。
# - 若 Mixed10k 构建正占 4 张卡，不要并行启动 S1/S3/S4/S5/S6；
#   项目总并发预算必须 <=4 GPU。

run_logged() {
  LOG_PATH=$1
  shift
  set +e
  "$@" 2>&1 | tee "${LOG_PATH}"
  COMMAND_RC=${PIPESTATUS[0]}
  printf '%s\n' "${COMMAND_RC}" > "${LOG_PATH}.exit_code"
  return "${COMMAND_RC}"
}
