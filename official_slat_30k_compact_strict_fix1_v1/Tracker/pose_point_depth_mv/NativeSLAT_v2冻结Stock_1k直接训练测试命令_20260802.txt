Native-SLAT v2：冻结 Native SS + Stock SLAT，1k 直接训练与测试命令（2026-08-02）
================================================================================

目的与固定口径
------------

本文件每一节都可以单独复制到终端运行。不要把整份文件当成一个自动脚本执行。

SLAT 阶段从本版本开始只有下面两个合法分支：

  Stock = Native SS step2000 EMA（固定采样参数）
          -> 原版冻结 Stock SLAT Flow
          -> 原版冻结 Mesh decoder

  Full  = 与 Stock 完全相同的 Native SS 坐标、原生图像 condition、初始噪声和 decoder
          -> Native-SLAT v2（SLAT attention LoRA
             + active 32^3 posed-DINO GenReCon every-block condition）

Native-SLAT v2 与成功的 Native SS v2 统一使用：条件/无条件 flow matching、p_uncond=0.1、
logit-normal t、随机视图子集、LoRA、every-block zero-init condition、EMA 和原版标准 CFG。
它不再使用 Direct-SLAT 的 condition_scale、post-CFG cap、wrong-support、teacher-forced
rollout 或 residual budget。Stock SLAT Flow base 和 Mesh decoder 全程冻结。

本轮按要求不做 2-object/5-step smoke，直接运行 reviewed 单物体 train868 长训。命令默认
使用两张卡，项目总卡数不得超过 4；TRAIN_GPUS 必须按实际空闲卡修改。
