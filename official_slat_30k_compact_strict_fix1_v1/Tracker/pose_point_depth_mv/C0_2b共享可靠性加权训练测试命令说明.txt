# C0.2b Correct-only共享可靠性加权训练与测试命令
# 日期：2026-07-17
#
# 一、当前模型与本阶段改动
#
# 网络结构保持不变：
#
#   per-view visual + pose/depth geometry
#                 |
#                 v
#   ViewCorrespondenceHead（同voxel、view-pair pooling）
#                 |
#       correct/control voxel_score
#
# C0.2b只增加训练loss权重：
#
#   correct evidence --detach--> reliability[x]
#                                  |
#                                  +--> correct-vs-pose rank
#                                  +--> correct-vs-depth rank
#                                  +--> correct-vs-visual rank
#
# reliability由以下correct-only量的几何平均组成：
#
#   view_support_fraction
#   pair_support_quality
#   depth_reliability = sqrt(depth_confidence * depth_consistency)
#   visibility_agreement
#
# 最终：
#
#   weight[x] = floor + (1-floor) * raw_weight[x] ** power
#
# inactive voxel权重严格为0。权重在进入loss前detach；correct和全部control
# 使用同一个weight与同一个fixed correct support，control不能通过缩小coverage获益。
#
# 以下内容相对C0.2a保持不变：
#
#   head参数与checkpoint tensor schema
#   evidence schema
#   train16/fresh48对象划分
#   随机view subset
#   sample BCE/rank、voxel BCE及其权重
#   三类training controls
#   C0.1 v2正式评估门
#
# 特别说明：正式评估仍对全部active voxel使用未加权门，不使用reliability
# 过滤低置信位置。因此C0.2b必须真正提升全coverage，不能靠训练权重修改验收集合。
#
# 二、预注册参数
#
#   --voxel_reliability_weighting correct_geometry
#   --voxel_reliability_floor 0.10
#   --voxel_reliability_power 1.0
#
# 其余C0.2a参数完全不变。
#
# 三、执行约定
#
# 1. 顺序执行V10.1 -> V10.2 -> V10.3 -> V10.4 -> V10.5 -> V10.6。
# 2. 每个外层命令块最终exit 0，不会因科学FAIL关闭当前终端。
# 3. 程序状态写入*.exit_code；科学判定写入*.decision_code。
# 4. 不使用--fail_on_decision。
# 5. 不覆盖已有目录；若目录不完整，记录98后人工检查或换名。
# 6. seed42 paired FAIL时停止，不运行seed43/44，不进入C1。
# 7. fresh48是development split；即使PASS仍需新的未查看holdout。
