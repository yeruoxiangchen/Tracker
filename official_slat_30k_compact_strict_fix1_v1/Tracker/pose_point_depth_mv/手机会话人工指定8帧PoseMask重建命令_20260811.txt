H0. 静态检查
============

cd /home/zjr/Tracker

PY=/home/zjr/anaconda3/envs/reconviagen/bin/python

${PY} -m py_compile \
  pose_point_depth_mv/reconstruct_existing_ar_session.py \
  pose_point_depth_mv/ar_object_reconstruction.py

${PY} -m unittest pose_point_depth_mv.test_ar_object_reconstruction

echo "current terminal remains open"


H1. 建议先只固化这8帧并运行PoseMask质量门，不加载模型
======================================================

cd /home/zjr/Tracker

PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
ROOT=/home/zjr/Tracker/pose_point_depth_mv/outputs/可视AR
SOURCE=20260811_023209_578
RUN=20260811_023209_578_manual8_v1

${PY} -u -m pose_point_depth_mv.reconstruct_existing_ar_session \
  --source_session_id "${SOURCE}" \
  --session_id "${RUN}" \
  --output_root "${ROOT}" \
  --gpu 6 \
  --frame_name frame_0000.jpg \
  --frame_name frame_0006.jpg \
  --frame_name frame_0012.jpg \
  --frame_name frame_0015.jpg \
  --frame_name frame_0017.jpg \
  --frame_name frame_0024.jpg \
  --frame_name frame_0027.jpg \
  --frame_name frame_0037.jpg \
  --diagnostic_bypass_pose_mask_qc \
  --selection_only

echo "selection report: ${ROOT}/reconstructions/${RUN}/phone_frame_selection_report.json"
echo "selected views: ${ROOT}/reconstructions/${RUN}/02_runtime_o/objects"
echo "current terminal remains open"

注意
====

1. 这组人工帧已确认不满足正式 PoseMask 几何门，因此 H1/H2 显式使用
   --diagnostic_bypass_pose_mask_qc。该开关只允许完成诊断推理，不会把失败指标
   改写成通过，也不能用于论文正式结果或手机部署通过声明。
2. 新数据集目录只包含这8张图像和mask；虽然复制的 poses.txt 还保留源会话的
   完整记录，但 sparse model、runtime-O和模型输入只绑定这8帧。
3. H1不会加载模型。H2会复用H1的raw/runtime结果并从DINO编码继续。
