Objaverse2K Stock-init vs 现有八卡 M8-init step800 八卡训练与测试
==================================================================

目标
----

只新训练一条八卡 Stock-init Objaverse2K 轨迹到800步，然后与已有结果比较：

1. Stock；
2. 历史 M8 step800；
3. 现有八卡 M8-init Objaverse2K step800；
4. 现有八卡 M8-init Objaverse2K step2000；
5. 新八卡 Stock-init Objaverse2K step800。

现有八卡 step800 checkpoint 直接作为 M8-init800 对照。新旧两条轨迹均使用八卡、
global batch8、seed42、相同学习率计划、相同训练集和800次 Objaverse2K optimizer
updates；计划差异只有初始化来源。因此这是初始化来源的 matched 主对照。

历史 M8 step800 继承更早的 real-domain checkpoint，不是 Stock-init，只作历史参考。

训练固定 GPU0-7；训练结束后的 dev16 评测使用 GPU1,2,6,7。下面命令假设 dev64 及
retry 已经完全结束，不等待、不轮询、不停止任何现有进程。GPU7 上仍可能有 capswriter
占约3.1 GiB；启动前应再次确认剩余显存足够。

step800 阶段停止。

S4. 结果读取
------------

主要看：

- stockinit800_vs_current_m8init800：新 Stock-init800 与现有八卡 M8-init800 的
  matched 初始化主对照；正值表示 Stock-init 更好。
- stockinit800_vs_stock：新训练是否真正超过原 Stock。
- current_m8init_objaverse2k800_vs_stock：现有八卡 M8-init800 是否超过 Stock。
- current_m8init800_vs_m8_step800：M8 warm-start 后增加800次 Objaverse2K updates
  相对历史 M8-800 的变化；预训练年龄不同，只作发展诊断。
- stockinit800_vs_current_m8init2000：新 Stock-init800 与当前长训终点比较。
- stockinit800_vs_m8_step800：与历史 M8-800 比较，包含预训练历史差异。

Stock-init800 四路归因：

- posed_dino_increment = correct - lora_only；
- correct_pose_specificity = correct - pose_cyclic1；
- generic_lora_increment = lora_only - stock；
- total_trained_slat = correct - stock。

所有 delta 均为 positive-is-left-better。优先同时看 Chamfer-L1、F@0.02、Normal、
object win rate 和 Chamfer bootstrap CI。Correct > Cyclic 但 Correct <= LoRA-only
仍只说明模型能识别 pose 对齐，不说明 posed-DINO 改善最终 Mesh。

dev16 用于 development/checkpoint selection，formal=false，不是最终 holdout。
