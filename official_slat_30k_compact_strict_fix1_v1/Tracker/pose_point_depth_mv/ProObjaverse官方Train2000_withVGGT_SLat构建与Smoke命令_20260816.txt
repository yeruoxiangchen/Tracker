Official Train2000 with-VGGT SLat：cache 构建与 smoke 命令
============================================================

说明：

1. 这些命令只创建新的 with-VGGT sidecar/output，不修改现有 no-VGGT cache。
2. Builder 永远读取 base lifting 中已冻结的 ordered view_ids，不重新筛图。
3. VGGT 只生成 SLat cross-attention context；不使用 VGGT camera/depth，不进入 SS。
4. 每个新 output 目录可以按原命令 resume；如果代码/权重/合同改变，必须换新版本目录。
5. 先完成 P0→P4；未通过前不要启动 F39 8卡正式 15K。
6. sidecar 不做人为 FP16 压缩：完整2K按 FP32 上界约84GiB规划；base cache约168GiB。
7. F39 数据盘建议至少400GiB；若同时保留raw staging建议500GiB，默认50GiB不足。
8. builder只加载真实执行的VGGT aggregator、DINO、slat_vggt_cond；不会加载Stock
   SS/Flow/decoder。训练rank沿用legacy Stock pipeline构造，可能短暂加载额外Stock/DINO
   模块，但不会重复加载VGGT；不能把它误写成“只加载Stock SLat”。


============================================================
P0. 公共变量与只读 preflight
============================================================

cd /home/zjr/Tracker
set -euo pipefail

export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1
export SPCONV_ALGO=native
export ATTN_BACKEND=flash_attn

PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
ROOT=/data/zjr/proobjaverse_official_slat_train2000_20260813_v1
SPLIT=${ROOT}/protocol2128_train2000_v1/train.json
BASE=${ROOT}/cache_train2000_protocol2128_views8_v1

"${PY}" -u -m \
  pose_point_depth_mv.prepare_proobjaverse_official_slat_with_vggt_sidecar \
  --mode preflight \
  --split_manifest "${SPLIT}" \
  --base_slat_manifest "${BASE}/slat_manifest.json" \
  --base_lifting_manifest "${BASE}/lifting_manifest.json" \
  --output_dir /tmp/official_train2000_with_vggt_preflight_v1 \
  --max_objects 8

预期：passed=true、object_count=8、exact_base_view_ids_only=true、
vggt_camera_consumed=false。preflight 不执行 VGGT forward，也不写 cache。

============================================================
P4. 同一 cache/checkpoint：1 GPU -> 2 GPU DDP/resume 到 step5
============================================================

CUDA_VISIBLE_DEVICES=0,1 torchrun --standalone --nproc_per_node=2 \
  -m pose_point_depth_mv.train_proobjaverse_official_slat_condition_lora_with_vggt \
  --cache_manifest "${OUT64}/with_vggt_slat_manifest.json" \
  --lifting_cache_manifest "${OUT64}/with_vggt_lifting_manifest.json" \
  --target_decoder_audit "${DECODER}" \
  --native_ss_report "${TRAINING_SS_REPORT}" \
  --stock_slat_freeze "${FREEZE}" \
  --output_dir "${SMOKE}" \
  --resume "${SMOKE}/checkpoints/step_000002.pt" \
  --max_steps 5 \
  --run_until_step 5 \
  --save_every 1 \
  --log_every 1 \
  --grad_accum 4 \
  --num_workers 0 \
  --allow_resume_topology_change

这里 world1xaccum8 和 world2xaccum4 都是 global batch=8。允许 topology change
只用于 smoke；optimizer/EMA继承，per-rank RNG stream 不宣称 exact。
