Native synthetic 1k no-VGGT ablation commands
==============================================

Purpose
-------
Run the no-VGGT ablation on the existing reviewed 1k synthetic split while the
real 500-object dataset is being built.

The original Native v2 Full entrypoints are not modified by these commands.
The no-VGGT path uses DINO-only visual tokens, pose/K/T, masks, point priors,
and the existing SS/SLat targets. VGGT features, VGGT depth, and VGGT model
execution are forbidden by the cache/checkpoint contracts.

Important
---------
The original Full lifting cache is not passed directly to the no-VGGT trainer.
First derive a DINO-only cache. This is a CPU/IO transformation of the existing
cache and does not execute VGGT again.

Each section is intended to be run as a separate shell command. Every command
uses a subshell and prints its own return code; it must not close the caller's
terminal. Choose GPUs that are actually idle before starting GPU stages.


0. Paths and source contract
----------------------------

4. Train no-VGGT Native SS from v2 Full EMA
---------------------------------------------

This is a new no-VGGT optimization trajectory. The parent optimizer, step,
history, and RNG are not inherited. Only the v2 Full EMA trainable state is
used for initialization.

Set NO_VGGT_SS_GPUS to an idle pair. The command below uses the same 2000-step
budget as the v2 Full SS run.

set +e
set +u
set +o pipefail
(
  set -euo pipefail
  cd /home/zjr/Tracker

  PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
  TORCHRUN=/home/zjr/anaconda3/envs/reconviagen/bin/torchrun
  NO_VGGT_SS_GPUS=${NO_VGGT_SS_GPUS:-3,4}
  RUN=/data/zjr/native_ss_no_vggt_mixed1k_20260807_v1
  TRAIN_LIFT=${RUN}/lifting_train868_dino_only_v1/lifting_manifest.json
  PARENT=/data/zjr/native3d_condition_ss_mixed1k_20260801_v1/ss868_sourceholdout_seed42_v1/checkpoints/step_002000.pt
  OUT=${RUN}/ss868_step2000_seed42_2gpu_v1
  LOG=${RUN}/logs/F4_ss868_step2000_seed42_2gpu.log

  test -s "${TRAIN_LIFT}"
  test -s "${PARENT}"
  if [ -s "${OUT}/report.json" ] && [ -s "${OUT}/checkpoints/step_002000.pt" ]; then
    echo "F4 reuse complete output: ${OUT}"
  else
    if [ -e "${OUT}/checkpoints/last.pt" ]; then
      RESUME_ARGS=(--resume "${OUT}/checkpoints/last.pt")
      echo "F4 resume: ${OUT}/checkpoints/last.pt"
    else
      RESUME_ARGS=(--init_checkpoint "${PARENT}" --init_weights ema)
      echo "F4 initialize from v2 Full EMA: ${PARENT}"
    fi
    CUDA_VISIBLE_DEVICES="${NO_VGGT_SS_GPUS}" \
    HF_HUB_OFFLINE=1 \
    TRANSFORMERS_OFFLINE=1 \
    ATTN_BACKEND=flash_attn \
    SPCONV_ALGO=native \
    MPLCONFIGDIR=/tmp/matplotlib \
    NUMBA_CACHE_DIR=/tmp/numba_cache \
    TORCH_EXTENSIONS_DIR=/tmp/torch_extensions \
    PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
    "${TORCHRUN}" --standalone --nproc_per_node=2 \
      -m pose_point_depth_mv.train_native_ss_genrecon_no_vggt \
      --cache_manifest "${TRAIN_LIFT}" \
      --output_dir "${OUT}" \
      --pretrained Stable-X/trellis-vggt-v0-2 \
      --indices all \
      "${RESUME_ARGS[@]}" \
      --max_steps 2000 \
      --save_every 200 \
      --log_every 10 \
      --grad_accum 8 \
      --num_workers 0 \
      --seed 42 \
      --lora_rank 8 \
      --lora_alpha 16 \
      --condition_channels 1024 \
      --new_lr 1e-4 \
      --lora_lr 3e-5 \
      --new_weight_decay 0.01 \
      --grad_clip 1.0 \
      --warmup_ratio 0.02 \
      --ema_decay 0.9995 \
      --p_uncond 0.1 \
      --t_logit_mean 1.0 \
      --t_logit_std 1.0 \
      --min_condition_views 1 \
      --max_condition_views 16 \
      --amp_dtype bf16 \
      --gradient_checkpointing \
      2>&1 | tee "${LOG}"
  fi
)
F4_RC=${PIPESTATUS[0]}
echo "F4_RC=${F4_RC}; current terminal remains open"

Stop conditions
---------------

- F1/F2 fail: inspect cache contract or disk space; do not train.
- F5 calibration fails: keep calibration.json for diagnosis; do not claim a
  successful no-VGGT SS gate.
- F6 fails: do not build the formal no-VGGT SLat training cache.
- F7/F8/F9 fail: do not start no-VGGT SLat training.
- A nonzero return code only ends the current subshell; the caller terminal is
  intentionally left open.
