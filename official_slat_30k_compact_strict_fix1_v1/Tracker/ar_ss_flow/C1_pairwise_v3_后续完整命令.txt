C1 pairwise-before-aggregation v3 后续完整命令
============================================================

目标：
1. 先审计 seed42 是否真正依赖 visual correspondence，而不是 geometry shortcut。
2. 同时验证 learned pairwise gate 是否优于 physical-weight-only 均值。
3. 只有消融门通过，才训练 seed43 / seed44。
4. 最后进行三 seed fresh-object 汇总。

约定：
- Tracker 根目录：/home/zjr/Tracker
- Python：/home/zjr/anaconda3/envs/reconviagen/bin/python
- Cache：/data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json
- seed42 现有 run：ar_ss_flow/outputs/corr_pairwise_v3_s200_seed42
- GPU 默认使用 0，可在运行前 export GPU=1 改为其他卡。

============================================================
A. 安装三个审计/汇总脚本
============================================================

将下载包 c1_pairwise_v3_next_tools.zip 放到服务器，例如：
/home/zjr/Downloads/c1_pairwise_v3_next_tools.zip

执行：

cd /home/zjr/Tracker || exit 1

unzip -jo \
  /home/zjr/Downloads/c1_pairwise_v3_next_tools.zip \
  -d ar_ss_flow/

/home/zjr/anaconda3/envs/reconviagen/bin/python -m py_compile \
  ar_ss_flow/eval_pairwise_ablation.py \
  ar_ss_flow/summarize_pairwise_ablation.py \
  ar_ss_flow/summarize_pairwise_v3_multiseed.py

确认参数：

/home/zjr/anaconda3/envs/reconviagen/bin/python \
  -m ar_ss_flow.eval_pairwise_ablation --help

脚本支持五种模式：
- full：完整模型；通常直接使用现有标准 eval report，不必重跑。
- visual_zero：只将 source visual feature 置零；held-out target 保持原始视觉特征。
- visual_shuffle：只在 source views 间循环打乱 visual feature；held-out target 保持原始。
- geometry_pair_off：将 learned geometry pair term 关闭，保留 visual pairwise term。
- uniform_pairwise：关闭 learned pairwise gate，退化为 physical-weight-only 均值聚合。

B. seed42：fresh48 四路消融
============================================================

cd /home/zjr/Tracker || exit 1
export GPU=${GPU:-0}

RUN=ar_ss_flow/outputs/corr_pairwise_v3_s200_seed42
ABL_ROOT=${RUN}/ablation_fresh48_sources2_3

for ABL in visual_zero visual_shuffle geometry_pair_off uniform_pairwise; do
  OUT=${ABL_ROOT}/${ABL}
  rm -rf "${OUT}"
  rm -f "${OUT}.log" "${OUT}.exit_code"

  echo "========== ablation=${ABL} =========="

  (
    CUDA_VISIBLE_DEVICES=${GPU} \
    /home/zjr/anaconda3/envs/reconviagen/bin/python -u \
      -m ar_ss_flow.eval_pairwise_ablation \
      --cache_manifest /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json \
      --checkpoint "${RUN}/checkpoints/last.pt" \
      --output_dir "${OUT}" \
      --indices 16-63 \
      --device cuda \
      --ablation "${ABL}" \
      --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse \
      --view_counts 3,4 \
      --neighborhood_radius 1 \
      --min_common_voxels 64
  ) 2>&1 | tee "${OUT}.log"

  STATUS=${PIPESTATUS[0]}
  echo "${STATUS}" | tee "${OUT}.exit_code"

  if [ "${STATUS}" -ne 0 ]; then
    echo "Ablation ${ABL} failed with status=${STATUS}"
    exit "${STATUS}"
  fi
done

四路都应为 exit_code=0。消融不是科学 PASS/FAIL evaluator，因此不会因性能下降而返回2。

退出码：
- 0：消融硬门通过，可继续 D--G。
- 2：消融硬门未通过，停止；不要训练 seed43/44，也不要进入 C2。
- 其他：程序或文件错误。

消融汇总硬门：
1. full 保持当前三类 hard negative 主门通过。
2. visual_zero 必须同时造成明显的 reprojection 与 pairwise 信号下降。
3. visual_shuffle 必须同时造成明显的 reprojection 与 pairwise 信号下降。
4. geometry_pair_off 后仍应保留正的 visual-only pairwise 信号。
5. learned pairwise gate 应优于 uniform_pairwise。

在继续前检查：

if [ "$(cat "${SUMMARY}.exit_code")" != "0" ]; then
  echo "Ablation gate did not pass. Stop here."
  exit 2
fi

done

三 seed 硬门：
- 每个 seed：finite、完成200步、至少2/3 hard negative通过；平均重建胜率不得低于50%。
- 每种 hard negative：三 seed 平均重建胜率 >=65%。
- 每种 hard negative：三 seed 平均 pairwise-confidence胜率 >=80%。
- mean / median reprojection advantage 和 pairwise advantage 都必须为正。

退出码：
- 0：C1 pairwise v3 消融与多seed门均通过，才允许设计C2接入。
- 2：科学门失败，停止，不进入C2。

最终执行纪律
============================================================

- C阶段 exit_code != 0：停止，不跑其他seed。
- G阶段 exit_code != 0：停止，不进入C2。
- 不因为某个单seed或某个hard negative看起来较好而跳过汇总门。
- 不降低65%门槛来追认成功。
- 不使用旧v1/v2 correspondence checkpoint接入C2。
