AR SS Flow：局部多视图 correspondence / held-out reprojection 命令说明
日期：2026-07-14

目标
====

本分支先完全不接 ReconViaGen Flow，验证：

  per-view [V,C] feature + mask/depth/visibility
    -> same-voxel local leave-one-view-out correspondence
    -> held-out patch reconstruction

在同一对象、同一图像集合下，correct pose 的重投影误差必须稳定低于：

  pose_cyclic1 / pose_cyclic2 / pose_reverse

cross_sample 只作为辅助 easy negative，不参与主门。

只有 C1 在 fresh object 上通过后，才进入 C2：

  correspondence confidence
    -> 聚合 visual volume
    -> weighted_support * correspondence_confidence hard gate
    -> same-voxel SS velocity residual

当前 /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714 缓存通常为 4 views，
因此本轮只测试 2-view / 4-view。要测试 8-view 趋势，必须先用真正含 8 个视图的
source cache 重新构建 lifting cache；不能在 4-view cache 上伪造 8-view。

12.1 C1 单 GPU s20 数值/梯度 smoke
=================================

说明：
  至少使用 4 个样本，cross_sample 才能找到不同对象的匹配形状负例。
  本阶段不加载 TRELLIS / ReconViaGen Flow。

(
set -uo pipefail
cd /home/zjr/Tracker

CACHE=/data/ar_ss_flow_pose_lifting_overfit64_v1_20260714
OUT=/home/zjr/Tracker/ar_ss_flow/outputs/corr_heldout_smoke4_s20_seed42

if [ -e "${OUT}" ]; then
  echo "output already exists: ${OUT}"
  exit 98
fi

CUDA_VISIBLE_DEVICES=1 \
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
/home/zjr/anaconda3/envs/reconviagen/bin/python -u \
  -m ar_ss_flow.train_heldout_correspondence \
  --cache_manifest "${CACHE}/manifest.json" \
  --output_dir "${OUT}" \
  --indices 0-3 \
  --device cuda \
  --seed 42 \
  --max_steps 20 \
  --save_every 20 \
  --log_every 1 \
  --lr 2.0e-4 \
  --weight_decay 1.0e-4 \
  --grad_clip 1.0 \
  --amp_dtype bf16 \
  --embedding_dim 128 \
  --geometry_hidden_dim 48 \
  --score_hidden_dim 192 \
  --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse,cross_sample \
  --neighborhood_radius 1 \
  --min_source_views 2 \
  --max_voxels_per_step 2048 \
  --min_common_voxels 64 \
  --rank_margin 0.05 \
  --score_margin 0.10 \
  --shortcut_margin 0.02 \
  2>&1 | tee "${OUT}.log"

CODE=${PIPESTATUS[0]}
echo "${CODE}" > "${OUT}.exit_code"
exit "${CODE}"
) || true

检查：
  train_report.json finite=true
  checkpoint 存在
  loss / grad_norm finite
  common_voxels >= 64
  normalized_advantage 不要求 s20 已经稳定为正，只要求非退化和能更新

12.3 C1 fresh-object held-out reprojection eval
===============================================

说明：
  训练使用 0-15；输入端生死门使用 fresh 16-63。
  correct/wrong 必须在 common support 上比较。
  4-view 是当前缓存的主门；2-view 只做趋势诊断。

cd /home/zjr/Tracker

for TRAIN_SEED in 42 43 44; do
(
set -uo pipefail

CACHE=/data/ar_ss_flow_pose_lifting_overfit64_v1_20260714
RUN=/home/zjr/Tracker/ar_ss_flow/outputs/corr_heldout_overfit16_s300_seed${TRAIN_SEED}
OUT=${RUN}/eval_fresh48_views2_4
GPU=$(( (TRAIN_SEED - 42) % 3 + 1 ))

if [ -e "${OUT}" ]; then
  echo "output already exists: ${OUT}"
  exit 98
fi

CUDA_VISIBLE_DEVICES=${GPU} \
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
/home/zjr/anaconda3/envs/reconviagen/bin/python -u \
  -m ar_ss_flow.eval_heldout_correspondence \
  --cache_manifest "${CACHE}/manifest.json" \
  --checkpoint "${RUN}/checkpoints/last.pt" \
  --output_dir "${OUT}" \
  --indices 16-63 \
  --max_samples 0 \
  --device cuda \
  --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse,cross_sample \
  --required_modes pose_cyclic1,pose_cyclic2,pose_reverse \
  --view_counts 2,4 \
  --neighborhood_radius 1 \
  --min_source_views 2 \
  --min_common_voxels 64 \
  --min_objects 16 \
  --min_object_win_rate 0.65 \
  --min_visual_score_advantage 0.0 \
  --min_visual_over_geometry_advantage 0.0 \
  --view_trend_tolerance 0.02 \
  --fail_on_error \
  2>&1 | tee "${OUT}.log"

CODE=${PIPESTATUS[0]}
echo "${CODE}" > "${OUT}.exit_code"
exit "${CODE}"
) || true
done

C1 每个 seed 的 report.json 必须满足：

  passed=true
  pose_cyclic1 / pose_cyclic2 / pose_reverse：
    4-view object_win_rate >= 0.65
    advantage mean > 0
    advantage median > 0
    visual_score_advantage mean >= 0
    visual_over_geometry_advantage mean >= 0
  4-view advantage 不应比 2-view 低超过 0.02

如果 identity 之后作为诊断加入，不能把它当普通 hard negative；identity 只用于检查 coverage shortcut。
