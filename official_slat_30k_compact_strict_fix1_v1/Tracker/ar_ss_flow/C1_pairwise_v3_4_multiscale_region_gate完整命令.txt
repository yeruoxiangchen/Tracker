C1 pairwise-v3.4 / C1.6：多尺度region gate完整命令
================================================================================

目标：
1. 不重新训练pairwise-v3 checkpoint。
2. 不再对单voxel confidence做局部平滑。
3. 用明确、不重叠的空间分区汇总raw visual-only confidence：
   - object：1个16×16×16区域；
   - octant8：2×2×2，共8个8×8×8区域；
   - grid64：4×4×4，共64个4×4×4区域；
   - octant8/grid64各自增加kappa=32、64的hierarchical shrinkage版本。
4. 区域confidence使用10% trimmed mean。
5. 每个volume内部把区域confidence转成percentile-rank spatial gate。
6. Shrinkage gate：
   alpha=N_eff/(N_eff+kappa)
   gate_region=alpha*rank_gate+(1-alpha)*matched_object_broadcast
7. 只在indices 0-15上选择尺度；indices 16-63完全冻结。
8. Region gate必须同时优于：
   - object/matched broadcast gate；
   - wrong-pose region gate；
   - visual-shuffle region gate。
9. seed43/44不重新选尺度，强制使用seed42冻结候选。
10. 只有三seed全部通过，才允许设计正式C2 SS Flow region-gate机制实验。

- Tracker：/home/zjr/Tracker

ensure_volume_audit () {
  SEED="$1"
  NAME="$2"
  INDICES="$3"
  RUN=ar_ss_flow/outputs/corr_pairwise_v3_s200_seed${SEED}
  OUT=${RUN}/deployment_local_audit_${NAME}_v2

  if [ "${FORCE_AUDIT}" != "1" ] && \
     [ -s "${OUT}/report.json" ] && \
     [ -s "${OUT}/volume_samples.npz" ]; then
    echo "Reusing ${OUT}"
    return 0
  fi

  rm -rf "${OUT}"
  rm -f "${OUT}.log" "${OUT}.exit_code"

  (
    CUDA_VISIBLE_DEVICES=${GPU} \
    /home/zjr/anaconda3/envs/reconviagen/bin/python -u \
      -m ar_ss_flow.audit_pairwise_local_deployment \
      --cache_manifest /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json \
      --checkpoint "${RUN}/checkpoints/last.pt" \
      --output_dir "${OUT}" \
      --indices "${INDICES}" \
      --device cuda \
      --seed "${SEED}" \
      --source_view_count 4 \
      --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse \
      --neighborhood_radius 1 \
      --min_source_views 2 \
      --min_common_voxels 64
  ) 2>&1 | tee "${OUT}.log"

  STATUS=${PIPESTATUS[0]}
  echo "${STATUS}" | tee "${OUT}.exit_code"
  if [ "${STATUS}" -ne 0 ]; then
    echo "Audit failed: ${OUT}"
    return "${STATUS}"
  fi
  test -s "${OUT}/report.json" || return 10
  test -s "${OUT}/volume_samples.npz" || return 11
}

if [ "${SEED42_STATUS}" = "0" ]; then
  for SEED in 43 44; do
    ensure_volume_audit "${SEED}" train16 0-15
    TRAIN_STATUS=$?
    if [ "${TRAIN_STATUS}" = "0" ]; then
      ensure_volume_audit "${SEED}" fresh48 16-63
      FRESH_STATUS=$?
    else
      FRESH_STATUS=99
    fi
    echo "seed=${SEED} train audit status=${TRAIN_STATUS}"

else
