C1 pairwise-v3.3：raw percentile / top-quantile gate 完整命令
======================================================================

目标：
1. 不重新训练 pairwise-v3 checkpoint。
2. 不再要求 raw confidence 成为单 voxel 概率分类器。
3. 直接利用已经验证过的对象内质量排序能力，比较 top 20%、30%、40%。
4. top fraction 只在 indices 0-15 上选择，在 indices 16-63 上冻结验证。
5. correct-confidence selector 必须优于三个等覆盖率对照：
   - random selector
   - wrong-pose confidence selector
   - visual-shuffle confidence selector
6. 只有 seed42 通过，才运行 seed43/44 的完整 volume audit 和多 seed 汇总。

约定：
- Tracker：/home/zjr/Tracker
- Python：/home/zjr/anaconda3/envs/reconviagen/bin/python
- Cache：/data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json
- 工具包：/home/zjr/Downloads/c1_pairwise_v3_3_percentile_tools.zip
- 默认 GPU=0，可先执行 export GPU=1 改卡。

退出码：
- 0：科学门通过。
- 2：程序正常完成，但科学门失败。
- 其他非零：文件、参数或程序错误。

本命令中的状态检查不会执行 exit 2，因此不会关闭当前交互式终端。

D. 只有seed42通过：为seed43/44生成或复用完整volume audit
======================================================================

cd /home/zjr/Tracker || exit 1
export GPU=${GPU:-0}
export FORCE_AUDIT=${FORCE_AUDIT:-0}

SEED42_STATUS=$(cat \
  ar_ss_flow/outputs/corr_pairwise_v3_s200_seed42/deployment_percentile_calibration_v3.exit_code \
  2>/dev/null || echo 99)

ensure_volume_audit () {
  SEED="$1"
  NAME="$2"
  INDICES="$3"
  RUN=ar_ss_flow/outputs/corr_pairwise_v3_s200_seed${SEED}
  OUT=${RUN}/deployment_local_audit_${NAME}_v2

  if [ "${FORCE_AUDIT}" != "1" ] && \
     [ -s "${OUT}/report.json" ] && \
     [ -s "${OUT}/volume_samples.npz" ]; then
    echo "Reusing existing ${OUT}"
    return 0
  fi

  rm -rf "${OUT}"
  rm -f "${OUT}.log" "${OUT}.exit_code"

  echo "===================================================================================================="
  echo "seed=${SEED} full-volume audit ${NAME}, indices=${INDICES}"

  (
    CUDA_VISIBLE_DEVICES=${GPU} \
    /home/zjr/anaconda3/envs/reconviagen/bin/python -u \
      -m ar_ss_flow.audit_pairwise_local_deployment \
      --cache_manifest /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json \
      --checkpoint "${RUN}/checkpoints/last.pt" \
      --output_dir "${OUT}" \
      --indices "${INDICES}" \
      --device cuda \
      --seed "${SEED}" \
      --source_view_count 4 \
      --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse \
      --neighborhood_radius 1 \
      --min_source_views 2 \
      --min_common_voxels 64
  ) 2>&1 | tee "${OUT}.log"

  STATUS=${PIPESTATUS[0]}
  echo "${STATUS}" | tee "${OUT}.exit_code"

  if [ "${STATUS}" -ne 0 ]; then
    echo "Audit failed: ${OUT}"
    echo "Inspect: tail -n 150 ${OUT}.log"
    return "${STATUS}"
  fi

  test -s "${OUT}/report.json" || { echo "Missing report.json"; return 10; }
  test -s "${OUT}/volume_samples.npz" || { echo "Missing volume_samples.npz"; return 11; }
  ls -lh "${OUT}/report.json" "${OUT}/volume_samples.npz"
}

if [ "${SEED42_STATUS}" = "0" ]; then
  for SEED in 43 44; do
    ensure_volume_audit "${SEED}" train16 0-15
    TRAIN_STATUS=$?

    if [ "${TRAIN_STATUS}" = "0" ]; then
      ensure_volume_audit "${SEED}" fresh48 16-63
      FRESH_STATUS=$?
    else
      FRESH_STATUS=99
    fi

    echo "seed=${SEED} train audit status=${TRAIN_STATUS}"
    echo "seed=${SEED} fresh audit status=${FRESH_STATUS}"
  done
else
  echo "seed42 percentile gate did not pass; skipping seed43/44 GPU audits."
fi
