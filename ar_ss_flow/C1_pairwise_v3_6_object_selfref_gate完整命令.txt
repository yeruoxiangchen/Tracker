C1.6-v2 Self-Referenced Object-level Scalar Gate
=================================================

重要变化：

旧的 deployment_local_audit_*_v2/volume_samples.npz 不能严格用于本实验。
旧文件只包含 correct、一次 wrong 和一次 visual shuffle；它没有把 wrong/shuffle
分别当作“当前观测”后重新施加 cyclic1/cyclic2/reverse。

本版本必须先运行新的 audit_pairwise_object_selfref：

  每个对象保存 5 个 observed hypothesis：
    correct
    pose_cyclic1
    pose_cyclic2
    pose_reverse
    visual_shuffle

  每个 observed hypothesis 都重新计算 4 个 variant：
    observed / identity
    pose_cyclic1
    pose_cyclic2
    pose_reverse

  self-reference score：
    score = statistic(observed)
            - reducer(statistic(three pose-perturbed variants))

不要复用 deployment_object_scalar_calibration_v5。
新输出统一使用：

  deployment_object_selfref_train16_v1
  deployment_object_selfref_fresh48_v1
  deployment_object_selfref_calibration_v6

ensure_selfref_audit () {
  SEED="$1"
  NAME="$2"
  INDICES="$3"

  RUN=ar_ss_flow/outputs/corr_pairwise_v3_s200_seed${SEED}
  OUT=${RUN}/deployment_object_selfref_${NAME}_v1

  if [ "${FORCE_AUDIT}" != "1" ] && \
     [ -s "${OUT}/report.json" ] && \
     [ -s "${OUT}/selfref_samples.npz" ]; then
    echo "Reusing ${OUT}"
    return 0
  fi

  rm -rf "${OUT}"
  rm -f "${OUT}.log" "${OUT}.exit_code"

  (
    CUDA_VISIBLE_DEVICES=${GPU} \
    /home/zjr/anaconda3/envs/reconviagen/bin/python -u \
      -m ar_ss_flow.audit_pairwise_object_selfref \
      --cache_manifest /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json \
      --checkpoint "${RUN}/checkpoints/last.pt" \
      --output_dir "${OUT}" \
      --indices "${INDICES}" \
      --device cuda \
      --seed "${SEED}" \
      --source_view_count 4 \
      --perturbation_modes pose_cyclic1,pose_cyclic2,pose_reverse \
      --min_source_views 2 \
      --min_common_voxels 64
  ) 2>&1 | tee "${OUT}.log"

  STATUS=${PIPESTATUS[0]}
  echo "${STATUS}" | tee "${OUT}.exit_code"
  echo "seed=${SEED} ${NAME} selfref audit status=${STATUS}"

  if [ "${STATUS}" -ne 0 ]; then
    return "${STATUS}"
  fi
  test -s "${OUT}/report.json" || return 10
  test -s "${OUT}/selfref_samples.npz" || return 11
}

================================================================================
状态解释
================================================================================

exit code 0：
  科学门通过。只有三seed总门也通过后，才进入object-gated C2。

exit code 2：
  程序正常，科学门失败。不要降低fresh门槛、不要重选配置。

其他非零：
  文件、CUDA、参数或程序错误。

运行时正式gate输入：

  同一个当前观测生成4个confidence volume：
    observed
    observed + pose_cyclic1
    observed + pose_cyclic2
    observed + pose_reverse

  score = selected_statistic(observed)
          - selected_reducer(three perturbed scores)

  g_object = clip((score - tau_low) / (tau_high - tau_low), 0, 1)

  cond_final = cond_base + g_object * delta_cond

本阶段仍未接入正式SS Flow；只验证self-reference object scalar是否能跨对象绝对标定。
