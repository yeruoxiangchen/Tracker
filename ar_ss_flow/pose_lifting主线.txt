Pose-guided Dense Visual Lifting 主线
日期：2026-07-13

目标
====

使用相机 K/T 将 VGGT/Image patch feature 显式提升到 SS 16^3 空间，形成 dense visual volume；
稀疏 AR/COLMAP point 只作为深度和局部几何锚点，不再承担完整对象识别。

固定约束
========

1. 部署输入只能使用 image、mask、pose 和真实可获得的 sparse point。
2. Mesh/GT latent 只能用于训练监督和评估，不能进入推理条件。
3. physical-off 必须严格退化到 stock condition、stock velocity 和 stock rollout。
4. 在 dense lifting 证明有效前，不启用普通 Flow LoRA，不训练 SLAT。

阶段 P0：坐标与数据审计
========================

1. 固定 world/canonical/camera/SS voxel 坐标约定。
2. 验证 K/T、c2w/w2c、camera forward sign、view 顺序和 patch flatten 顺序。
3. 完成 voxel -> view patch -> ray/depth -> voxel sentinel round-trip。
4. 统计 mask、VGGT depth、sparse point 和 visual hull 的有效覆盖率与冲突率。
5. 使用 sparse point 将 VGGT depth 标定到 camera depth，分别审计 scale-only 与 affine：

     z_camera ~= a * depth_vggt
     z_camera ~= a * depth_vggt + b

   必须记录匹配点数、scale/shift、median/P90 residual 和失败率。匹配不足时显式关闭
   depth consistency，回退到 mask/visual-hull 权重，禁止静默使用默认尺度。

阶段 P1：离线缓存可复用视觉内容与 lifting inputs
================================================

1. 离线保存每个 view 的 VGGT patch、DINO/Image patch、mask、VGGT depth/confidence、K/T、
   view 顺序、sparse points、canonical transform 和 stock SS condition。
2. stock condition 保持原 ReconViaGen alpha crop/recenter；用于几何 lifting 的视觉特征使用
   不裁剪的 full-frame masked resize，并把 K 同步缩放到该 518x518 坐标系。
3. correct pose 的 voxel->patch/image grid、camera depth、valid projection 可以保存为 FP32
   加速缓存，但不是唯一表示。
4. 训练/评估时从同一份 patch feature 重建 correct pose、small pose perturbation、shuffled pose
   和 depth corruption volume。corruption 只改变几何/深度采样路径，不重新编码图像。
5. 对每个 16^3 voxel 使用 mask、visibility、标定后的 depth consistency 和 confidence 聚合
   F_3D，并保存 support/depth/prior/XYZ metadata。

阶段 P2：未训练可分性与机制审计
==============================

固定 image 和 voxel，比较：

  correct pose
  small pose perturbation
  shuffled pose
  depth corruption
  null physical

检查 correct pose 是否提高跨 view feature consistency，并确保错误 pose 显著破坏对应关系。
若输入 volume 本身不可分，停止训练并修复几何或深度构建。

阶段 P3：SS Flow spatial adapter smoke
====================================

1. 第一版禁止 4096x4096 global cross-attention。SS noisy latent/stock velocity 与 F_3D 已处于
   同一 16^3 坐标系，只做同 voxel pointwise interaction：

     [W_h(h_i), W_v(v_i), W_h(h_i)*W_v(v_i),
      abs(W_h(h_i)-W_v(v_i)), support_metadata_i]
       -> pointwise MLP -> zero-init velocity delta_i

2. 当前实现将 h_i 定义为同位置的 x_t 与 frozen stock velocity 编码；不修改 frozen Flow 内部 block。
3. 输出由 weighted support 硬门控。physical_present=false 或 null volume 时 bit-exact stock。
4. 后续只有同位置版本通过，才允许 3x3x3/最多 27 个 K/V 的 local attention；仍禁止全局 attention。
5. 完成 stock equivalence、gradient、BF16 finite、checkpoint finite 和单样本 s5 审计。

阶段 P4：overfit16 三 seed
=========================

训练目标先只使用：

  global flow matching
  correct-pose gain
  corrupted-pose -> stock
  unsupported/neutral-region hard stock preservation
  delta norm

使用 fixed noise、多个 t、三个 seed。必须同时通过 correct-vs-stock、correct-vs-corrupted、
object-balanced win rate 和空间局部指标，不能只看平均 Flow MSE。

阶段 P5：fresh overfit64 与 object-disjoint validation
=====================================================

只有 P4 三 seed 全 PASS 才运行 fresh overfit64；不得从 overfit16 checkpoint resume。
overfit64 通过后再进入完整 train/validation/holdout，并按 object 聚合指标。

阶段 P6：加入稀疏锚点局部监督
============================

确认 decoder occupancy/logit 路径可微后，加入：

  point-neighborhood positive
  reliable outside/visual-hull negative
  unsupported-region stock preservation

若不可微，只能使用明确命名的 latent/flow proxy，不能把 threshold coords 当作训练 loss。

阶段 P7：扩大容量
================

只有 dense volume 和 sparse anchor 均在 validation 上提供稳定收益后，才依次尝试：

  physical-gated Flow LoRA
  更多 Flow block
  弱 occupancy/precision loss
  SLAT conditioning

每次只增加一个变量。

停止条件
========

1. correct/shuffled pose volume 在 P2 不可分：停止并修复几何，不训练。
2. P4 无法跨三 seed 建立 correct > corrupted：停止当前 adapter 结构。
3. 只改善训练对象、不改善 object-disjoint validation：不进入 Flow LoRA/SLAT。
