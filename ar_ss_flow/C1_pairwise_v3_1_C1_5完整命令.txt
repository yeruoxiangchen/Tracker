C1 pairwise v3.1 + C1.5 visual-only deployment calibration 完整命令
====================================================================

目的：
1. 修正 v3 标准评估器：未训练的 legacy visual/geometry score head 仅作诊断，不再影响 PASS/FAIL。
2. 不重新训练已有 seed42/43/44 checkpoint，只重新生成 v3.1 标准评估。
3. 使用 4 个 source view、无 held-out 的真实部署形式审计 visual-only pairwise confidence。
4. 使用 4 source + 1 held-out 的固定目标 probe 做 voxel-level 阈值校准。
5. 阈值只在 indices 0-15 上选择，在 indices 16-63 上冻结验证。
6. seed42 先过门，再运行 seed43/44；最后检查阈值跨 seed 稳定性。

cd /home/zjr/Tracker || exit 1
export GPU=${GPU:-0}

for SEED in 42 43 44; do
  RUN=ar_ss_flow/outputs/corr_pairwise_v3_s200_seed${SEED}

  for SPLIT in train fresh; do
    if [ "${SPLIT}" = "train" ]; then
      INDICES=0-15
      MIN_OBJECTS=8
      EVAL=${RUN}/eval_train16_sources2_3_v31
    else
      INDICES=16-63
      MIN_OBJECTS=16
      EVAL=${RUN}/eval_fresh48_sources2_3_v31
    fi

    rm -rf "${EVAL}"
    rm -f "${EVAL}.log" "${EVAL}.exit_code"

    echo "======================================================================"
    echo "v3.1 standard eval seed=${SEED} split=${SPLIT}"
    echo "======================================================================"

    (
      CUDA_VISIBLE_DEVICES=${GPU} \
      /home/zjr/anaconda3/envs/reconviagen/bin/python -u \
        -m ar_ss_flow.eval_heldout_correspondence \
        --cache_manifest /data/ar_ss_flow_pose_lifting_overfit64_v1_20260714/manifest.json \
        --checkpoint "${RUN}/checkpoints/last.pt" \
        --output_dir "${EVAL}" \
        --indices "${INDICES}" \
        --device cuda \
        --negative_modes pose_cyclic1,pose_cyclic2,pose_reverse,cross_sample \
        --required_modes pose_cyclic1,pose_cyclic2,pose_reverse \
        --view_counts 3,4 \
        --neighborhood_radius 1 \
        --min_common_voxels 64 \
        --min_objects "${MIN_OBJECTS}" \
        --min_object_win_rate 0.65 \
        --min_pairwise_win_rate 0.65 \
        --min_pairwise_confidence_advantage 0.0 \
        --view_trend_tolerance 0.02 \
        --fail_on_error
    ) 2>&1 | tee "${EVAL}.log"

    STATUS=${PIPESTATUS[0]}
    echo "${STATUS}" | tee "${EVAL}.exit_code"

    if [ "${STATUS}" -ne 0 ]; then
      echo "v3.1 eval failed: seed=${SEED}, split=${SPLIT}, status=${STATUS}"
      exit "${STATUS}"
    fi
  done
done

阶段纪律
====================================================================

1. C/D 未通过：说明标准 v3.1 门仍有问题，停止。
2. seed42 F 返回 2：visual-only confidence 在真实部署形式下不可校准，停止，不进入 C2。
3. H 返回 2：阈值或性能跨 seed 不稳定，停止，不进入 C2。
4. H 返回 0：冻结 seed42 checkpoint 与 seed42 calibration.json，下一步实现 C2 五路机制门：
   - stock
   - correct learned-confidence gate
   - wrong-pose learned-confidence gate
   - uniform gate
   - visual-shuffled confidence gate
5. C2 第一轮不挑 seed44，不增加训练步数，不直接做完整 mesh 长流程。
