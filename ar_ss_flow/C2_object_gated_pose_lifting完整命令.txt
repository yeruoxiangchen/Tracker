================================================================================
F. 结果解释纪律
================================================================================

正式通过必须同时满足：
  residual_off == stock bit-exact
  correct gate fresh mean/median gain > 0
  至少4/5个t为正
  correct gate > fresh matched constant
  correct gate > permuted correct gate
  correct gate > cyclic1/cyclic2/reverse/shuffle gates

注意：
  matched constant 使用 fresh correct gate 的均值，只匹配平均残差强度，不使用Flow标签。
  permuted gate 保留完整gate分布，只打乱对象绑定。
  因此 correct > constant/permuted 才能证明对象特异gate有因果价值。
