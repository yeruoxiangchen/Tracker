Objaverse2K 四卡 no-VGGT Native-SLat v2 训练与测试
===================================================

实验身份
--------

- 冻结源快照：2199 objects / 4137 sequences / render shards 000-007。
- 冻结 SS：当前 mixed no-VGGT SS step2000 EMA，25 steps / CFG3。
- SLat 初始化：当前 M8 SLat step2000 EMA；不继承 optimizer、旧 step 或旧 EMA。
- 新训练划分：train=2135 objects，dev=64 objects；对象严格互斥。
- Audit64 不作为 dev；其 64 个对象保留在未来 train2135 中，继续保持
  `formal=false, training_overlap=true` 的 support gate 身份。
- 四卡 DDP：默认物理 GPU 0,5,6,7；每卡 batch=1，grad_accum=2，
  global effective batch=4*2=8。
- Native-SLat architecture=v2；Stock cross-attention=all views；
  posed-DINO 3D=all selected views。
- max_steps 永久固定为 2000。`run_until_step` 只用于 400/800/... 暂停，
  不改变 checkpoint 身份或学习率计划。
- dev64 是 checkpoint selection 集，不是 formal holdout；Objaverse16 只在最终选点后跑一次。

P2. 四卡准备 train/dev64、GT SLat target、frozen-SS cache
--------------------------------------------------------

该脚本依次执行：

1. 固化 train2135/dev64，并生成对象不跨 worker 的四卡 indices；
2. CPU 全量预检 2199 对象的原生 target 身份和跨序列坐标 IoU；
3. 四卡并行构建 native Objaverse local lh-slats；
4. 四卡并行构建 train seed42 cache 并无复制汇总；
5. 四卡并行构建 dev seeds42,43,44 cache 并无复制汇总；
6. 在 dev32 上执行 frozen mesh decoder target audit。

它不会伪造 `object_level_ss_repair.v1`。原始 renderer latent 使用独立的
`native_objaverse_render_v1` 契约。同一对象的 target 固定取 UID 字典序最小的 primary
sequence；其余 sequence 的 RGB/mask/camera 仍参与 DINO 融合，但独立 surface voxelization
得到的 coords/z 不要求逐元素相同。rotation/source GLB 必须完全相同，跨 sequence coords
IoU 必须不低于 0.75。train/dev manifest 固定按 `(object_uid, uid)` 排序，因此下游
`min_frame_iou=0.90` 检查读取的第一条 SS sequence 与 primary target 是同一份坐标，而不是
用 0.75 放宽训练坐标帧门。

真实 2199-object CPU 预检已通过：4137 sequences、1938 次双序列比较，IoU min=0.7710758、
p01=0.9115384、p05=0.9354552、median=0.9726006，低于0.75为0；rotation和source GLB在
1938/1938比较中完全一致。

P4C. 四卡 dev16 四路归因：posed-DINO 与 LoRA-only
-------------------------------------------------

该测试只加载一个 Objaverse2K checkpoint，四个分支为：

- stock：关闭 LoRA 和 posed-DINO residual；
- lora_only：保留训练后的 LoRA，但用 forward hook 将完整 every-block
  condition 输出严格置零，包括 projection bias；
- pose_cyclic1：保留 LoRA/posed-DINO，但相机 pose 循环错配一位；
- correct：保留 LoRA/posed-DINO 和正确 image/pose binding。

同一 object/support-seed 的四路共享 frozen Native-SS coordinates、initial noise、
Stock image context、sampler 和 decoder，并在同一个进程内依次执行。不要把四个分支
拆到四张卡，否则 sparse CUDA 的跨进程数值波动会混入分支差异。

GPU0/3/4/5 各处理 frozen dev64 顺序中的前 16 个对象里的 4 个对象；每对象使用
support seeds 42/43/44。因此共有 16 objects、48 matched quartets、192 branch rollouts。
统计先对每个对象的 3 seeds 求均值，再在 16 个对象上算 win rate 和 bootstrap CI。
