用途
====

这份命令只回答一个问题：当前 Native SS 是否可以继续冻结，而不必因官方
ProObjaverse SLat 长训而重训 SS。

严格比较：

  同一批官方 ProObjaverse Dev64 的 8 视图 DINO/pose/mask
    -> Stock SS 和当前 Native SS（相同 SS 初始噪声）
    -> 两份 predicted occupancy
    -> 同一个冻结 Stock SLat（相同图像条件、相同坐标键噪声）
    -> 同一个冻结 Mesh decoder
    -> 官方 SLat label 解码得到的 target Mesh

注意：

  1. 官方包没有单独发布 SS latent，本测试不会伪造 latent-MSE。
  2. 官方 SLat 坐标/特征只作为 occupancy/Mesh 标签，不会喂给 SS 推理。
  3. 这是 Dev64 开发裁决，不是最终 untouched claim。
  4. 两卡只改变耗时，不改变样本、随机种子或裁决规则。

T3. 两卡后台运行官方 Dev64（每卡32对象，seed 42/43/44）
=========================================================

默认用 GPU 0,5。修改 EVAL_GPUS 即可，但必须恰好两个 GPU id。
每个分片可断点续跑；重复执行本段会复用已经完成的 pair。

cd /home/zjr/Tracker

PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
EVAL_GPUS=${EVAL_GPUS:-0,5}
ROOT=/data/zjr/proobjaverse_official_slat_train2000_20260813_v1
CACHE=${ROOT}/cache_dev64_protocol2128_views8_v1
SS_REPORT=/data/zjr/native_no_vggt_mixed_real376_synth868_20260808_v1/ss_eval_synthetic_dev32_fixedcfg3_count125_v3/report.json
STOCK_FREEZE=/data/zjr/native_slat_genrecon_v2_mixed1k_20260802_v1/stock_slat_freeze_v2.json
OUT_ROOT=/data/zjr/proobjaverse_official_dev64_native_ss_stock_slat_20260814_v1/dev64_seed424344_2gpu_v1

if [ "$(awk -F, '{print NF}' <<<"${EVAL_GPUS}")" -ne 2 ]; then
  echo "T3 blocked: EVAL_GPUS must contain exactly two GPU ids"
else
  IFS=, read -r GPU0 GPU1 <<<"${EVAL_GPUS}"

  for SPEC in "0 ${GPU0} 0 32" "1 ${GPU1} 32 64"; do
    read -r SHARD DEVICE START END <<<"${SPEC}"
    UNIT=tracker-official-dev64-native-ss-slat-shard${SHARD}-v1
    OUT=${OUT_ROOT}/shard${SHARD}_${START}_${END}

    if [ -s "${OUT}/report.json" ]; then
      echo "reuse complete shard${SHARD}: ${OUT}/report.json"
    elif systemctl --user is-active --quiet "${UNIT}.service"; then
      echo "already running: ${UNIT}.service"
    else
      EXTRA=()
      if [ -e "${OUT}" ]; then EXTRA+=(--resume); fi
      systemd-run --user \
        --unit="${UNIT}" \
        --collect \
        --working-directory=/home/zjr/Tracker \
        env \
          CUDA_VISIBLE_DEVICES="${DEVICE}" \
          HF_HUB_OFFLINE=1 \
          TRANSFORMERS_OFFLINE=1 \
          ATTN_BACKEND=flash_attn \
          SPCONV_ALGO=native \
          MPLCONFIGDIR=/tmp/matplotlib \
          NUMBA_CACHE_DIR=/tmp/numba_cache \
          TORCH_EXTENSIONS_DIR=/tmp/torch_extensions \
        "${PY}" -u -m pose_point_depth_mv.evaluate_proobjaverse_official_native_ss_stock_slat \
          worker \
          --cache_manifest "${CACHE}/slat_manifest.json" \
          --lifting_cache_manifest "${CACHE}/lifting_manifest.json" \
          --native_ss_report "${SS_REPORT}" \
          --stock_slat_freeze "${STOCK_FREEZE}" \
          --output_dir "${OUT}" \
          --joint_seeds 42,43,44 \
          --object_start "${START}" \
          --object_end "${END}" \
          --surface_samples 20000 \
          --amp_dtype bf16 \
          "${EXTRA[@]}"
    fi
  done
fi

echo "current terminal remains open"
