Objaverse约5K单语义主体分层构建命令（2026-08-10）
=====================================================

目标与边界
----------

本流程从已经完成源Mesh审计的29,999个Objaverse对象中冻结5,000个新对象：

  source-clean候选  3,750（75%）
  source-hard候选   1,250（25%）
  reserve补位对象     512（默认不渲染）

hard池保留multipart/附件、细长结构、复杂高面数、低dominant-area和已观测低纹理对象。
C类scene-like候选和R类无效Mesh不进入；旧Mixed1k train/val/test及Objaverse16按UID、
规范化source_glb和可用source hash排除。

重要：A1只冻结源GLB，不会伪装成training-ready。A3/A4渲染后仍必须运行A6，对RGB、Mask、
相机取景、投影支持和纹理做第二层QC。source-clean/source-hard不是人工语义真值。

大文件输出全部放在/data/zjr；命令文档和代码仍位于原pose_point_depth_mv目录。

A4. 正式5K多GPU渲染（后台，不依赖当前终端）
=============================================

# 现有实测约21--22秒/24-view sequence。5,000对象x2 sequence约60 GPU-hours；
# 4卡约15--18小时，8卡约7.5--10小时，另加IO和失败重试波动。
# 按空闲卡修改GPU_LIST_CSV；所有worker必须保持完全相同的参数。

cd /home/zjr/Tracker
PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
BLENDER=/tmp/blender-3.0.1-linux-x64/blender
FREEZE=/data/zjr/objaverse5k_single_subject_stratified_20260810_v1
RENDER=/data/zjr/objaverse5k_single_subject_render512_20260810_v1
PREVIEW=/data/zjr/objaverse5k_single_subject_render512_previews_20260810_v1
LOG_ROOT=/data/zjr/objaverse5k_single_subject_render512_logs_20260810_v1
GPU_LIST_CSV=${GPU_LIST_CSV:-1,2,3,4}

IFS=',' read -r -a GPU_LIST <<<"${GPU_LIST_CSV}"
NUM_WORKERS=${#GPU_LIST[@]}
test "${NUM_WORKERS}" -gt 0
test -x "${BLENDER}"
test -s "${FREEZE}/build_plan.json"

for WORKER_INDEX in "${!GPU_LIST[@]}"; do
  GPU_INDEX=${GPU_LIST[${WORKER_INDEX}]}
  UNIT=objaverse5k-render-w${WORKER_INDEX}-20260810-v1

  systemctl --user reset-failed "${UNIT}" >/dev/null 2>&1 || true
  systemd-run --user \
    --unit="${UNIT}" \
    --collect \
    --property=WorkingDirectory=/home/zjr/Tracker \
    /usr/bin/env \
      CUDA_VISIBLE_DEVICES="${GPU_INDEX}" \
      HF_HUB_OFFLINE=1 \
      TRANSFORMERS_OFFLINE=1 \
      PYOPENGL_PLATFORM=egl \
      ATTN_BACKEND=flash_attn \
      SPCONV_ALGO=native \
      MPLCONFIGDIR=/tmp/matplotlib \
      NUMBA_CACHE_DIR=/tmp/numba_cache \
      TORCH_EXTENSIONS_DIR=/tmp/torch_extensions \
      PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
    "${PY}" -u \
      pose_point_depth_mv/dataset_tools/run_mixed_multiview_render_worker.py \
      --source_plan "${FREEZE}/build_plan.json" \
      --render_root "${RENDER}" \
      --preview_root "${PREVIEW}" \
      --log_root "${LOG_ROOT}" \
      --worker_index "${WORKER_INDEX}" \
      --num_workers "${NUM_WORKERS}" \
      --sources objaverse \
      --python "${PY}" \
      --blender_path "${BLENDER}" \
      --blender_engine CYCLES \
      --blender_samples 16 \
      --blender_bounds_tolerance 0.001 \
      --blender_cycles_device CUDA \
      --seed 20260810 \
      --sequences_per_object 2 \
      --candidate_views 24 \
      --selected_views 8 \
      --vis_count_per_shard 8 \
      --max_objects_per_shard 0

  echo "${UNIT}: GPU=${GPU_INDEX}, worker=${WORKER_INDEX}/${NUM_WORKERS}"
done
