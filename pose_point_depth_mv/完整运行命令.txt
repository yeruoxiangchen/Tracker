# ============================================================================
# PPD-3A：16^3 local-target learnability probe（2026-07-15）
# ============================================================================
#
# 当前模型结构：
#
#   frozen ReconViaGen stock SS Flow
#       x_t + stock_condition -> v_stock
#
#   strict PPD evidence cache（17通道，16^3）：
#       correct + 6种paired corruption
#       pose_cyclic1 / pose_reverse
#       depth_view_cyclic1 / depth_spatial
#       point_reflect / point_cross_object
#
#   trainable probe（约1k参数，rank=16/32）：
#       state = [x_t(8), v_stock(8), t/1000(1)]
#       state_hidden = 1x1x1 Conv(state)
#       evidence_hidden = 1x1x1 Conv(PPD evidence)
#       interaction = [evidence_hidden,
#                      state_hidden * evidence_hidden]
#       delta = zero-init 1x1x1 low-rank MLP(interaction)
#       delta *= (positive_label OR negative_label)
#
#   没有全局attention；没有跨voxel mixing；没有加载旧C2 residual；
#   physical-off、null evidence（保留XYZ）和neutral voxel严格输出零。
#
# 训练目标：
#   correct active voxel -> v_gt - v_stock
#   corruption active voxel -> 0
#   correct flow gain > 0
#   correct flow loss < paired corruption flow loss
#
# 目的：先回答“严格几何证据能否在SS Flow的同体素局部目标上被学习”。
# PPD-3A PASS之后才实现更大的PPD-3B adapter；FAIL则停止继续扩大该分支。

# ============================================================================
# V4 Point-only Local-anchor V2（2026-07-15）
# ============================================================================
#
# 目标：
#   对聚合17通道PPD路线做完停止诊断后，只保留证据最明确的稀疏点局部锚点。
#   本阶段不再输入pose/depth，不训练bridge，不训练原SS Flow，也不启用Flow LoRA。
#
# 模型结构：
#   frozen ReconViaGen stock condition + frozen stock SS Flow
#                           |
#            x_t + v_stock + normalized t
#                           |
#   point evidence: occupancy/confidence/distance + active/neutral + XYZ
#                           |
#             same-voxel low-rank probe（3104 params, rank=32）
#                           |
#       delta * fixed_correct_point_mask * physical_scale
#                           |
#                    v_stock + delta
#
# 关键协议：
#   1. point active区域是16^3中距correct point <= 1 voxel的并集；
#   2. 最多确定性保留512点，防止稠密样本把“局部锚点”变成全局修改；
#   3. train16和fresh48内部分别选择cross-object control，禁止跨split借负样本；
#   4. correct/control确定性下采样到共同点数，confidence多重集合严格相同；
#   5. correct与六种control全部使用correct active mask；
#   6. 每个optimizer update同时训练全部六种control：
#      reflect / axis-cycle / spatial-roll / matched-cross-object /
#      point-drop(active-mask-only) / constant-prior；
#   7. physical-off、null evidence、非anchor位置必须bit-exact stock；
#   8. 所有命令外层最终exit 0，不会因科学FAIL关闭当前终端；真实状态写入.exit_code。
#
# 已完成的开发验证：
#   - 26个相关单元/回归测试通过；
#   - 全64对象cache smoke PASS；
#   - active ratio mean/max = 0.1024 / 0.2944；
#   - 单步BF16训练、反向、optimizer、checkpoint、finite audit均PASS。
#
# 不能复用：
#   旧PPD-3A checkpoint、旧17通道probe cache、旧point residual checkpoint。
#

# ==========================================================================
# V6 View-identity Pose-guided Visual Lifting V1（2026-07-16）
# ==========================================================================
#
# 当前模型结构：
#
#   frozen per-view VGGT(2048) + DINO(1024) patch features
#                         │
#                         ├── K/T投影到canonical 16^3 voxel
#                         ├── calibrated VGGT depth/depth confidence
#                         ├── mask/visibility
#                         └── world ray + camera origin + patch uv
#                                      │
#                                      ▼
#                      [view, voxel, visual/geometry token]
#                                      │
#                 same-voxel pairwise visual consistency（保留view维）
#                                      │
#       SS state query(x_t + positive stock velocity + t + canonical xyz)
#                                      │
#                         same-voxel view attention
#                                      │
#                         zero-centered local residual
#                                      │
#                  native guided stock velocity + local delta
#
# 关键边界：
#   - view维一直保留到每个voxel内部attention之后，不再提前mean/max；
#   - 不使用4096x4096全局attention，不混合不同voxel；
#   - correct/corrupt训练与主评估共享correct view weight和support gate；
#   - frozen ReconViaGen bridge、SS Flow、decoder；Flow LoRA关闭；
#   - physical-off、null evidence和非support区域严格退化到stock；
#   - 点云只通过既有cache参与VGGT depth标定，本版不直接输入point anchor。
#   - 当前cache仍使用数据集提供的pixal3d_rotation canonical frame；V6只验证
#     view identity是否能把pose/depth信号传到SS Flow，不宣称已经解决真实AR中
#     “未知物体位姿/未知canonical frame”的在线估计问题。
#
# Controls：
#   pose_cyclic1, pose_reverse,
#   depth_view_cyclic1, depth_spatial,
#   visual_view_cyclic1
#
# 所有命令块最终exit 0，不会关闭当前终端。真实程序返回码写入
# *.exit_code，科学裁决写入*.decision_code或report.json。
