Native-SLAT v3：去固定平均、学习式逐层多视图融合训练测试逐步命令（2026-08-03）
================================================================================

使用说明
--------

1. 本文件不是一键脚本。每一节单独复制到终端执行，确认上一节通过后再运行下一节。
2. 不修改、不覆盖已经冻结的 Native SS、Stock-SLAT、v2 训练结果或 cache。
3. 默认训练使用 GPU 4,5，评估使用 GPU 5；运行前必须按 nvidia-smi 改为空闲卡。
4. 本项目同时占用的 GPU 总数不得超过 4。
5. 长训和完整 Mesh 评估使用 user-systemd，关闭当前终端不会终止任务。

固定比较口径
------------

  Stock = Native SS step2000 EMA
          -> ReconViaGen 发布版 Stock-SLAT（保留原代码逐视图算术平均）
          -> 冻结 Mesh decoder

  Full  = 与 Stock 相同的 Native SS 坐标、原生 SLat condition、初始噪声、采样器和 decoder
          -> Native-SLAT v3：
             * attention LoRA
             * active 32^3 posed-DINO every-block condition
             * 每个 SLat transformer block 对每个视图分别做 cross-attention
             * 用 cross-attention result MLP + posed-DINO 可见性 logit 学习逐点视图权重
             * 学习目标对无效投影视图显式 mask；过渡门从 Stock 均值连续打开
             * 全部视图均无效时回退均匀权重

关键安全边界：没有删除 ReconViaGen/Stock 的平均。学习式融合只存在于 Full 分支。
每层 transition gate 从精确 0 初始化，因此初始 Full 前向严格等于 Stock；训练只让 Full
连续地从均匀权重转向非均匀权重。Stock 权重、Stock 平均、Native SS 和 decoder 均冻结。

本版本继续复用 v2 的 immutable 数据契约和冻结文件：
