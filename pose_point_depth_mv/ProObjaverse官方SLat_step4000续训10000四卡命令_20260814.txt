ProObjaverse 官方 SLat：保留当前 step4000 阶段并续训到 step10000
=================================================================

说明
----

- 不停止当前 tracker-proobj-official-slat-b-train-step4000-v1.service。
- 先等待当前任务生成完整的 step_004000.pt 和 stage_report_step_004000.json。
- step4000 完成后，从四卡和八卡方案中选择一个运行，不要同时运行。
- 四卡：GPU 1,2,3,4，world_size=4，grad_accum=2，global batch=8。
- 八卡：GPU 0-7，world_size=8，grad_accum=1，global batch=8；八卡必须全部空闲。
- 原 checkpoint 固定 max_steps=8000，因此续训时必须显式传入
  --allow_resume_max_steps_extension。模型、optimizer、EMA 和 RNG 均从 step4000
  继承。八卡方案会显式记录 DDP 拓扑切换，且不声称逐 rank RNG 流完全一致。

==========================

watch -n 20 'date -u; systemctl --user is-active tracker-proobj-official-slat-b-train-step4000-v1.service || true; tail -n 5 /data/zjr/proobjaverse_official_slat_train2000_20260813_v1/logs/L6_train2000_step002000_to_004000_4gpu.log 2>/dev/null || true'


T1. 确认 step4000 完整完成
==========================

cd /home/zjr/Tracker
set -euo pipefail

RUN=/data/zjr/proobjaverse_official_slat_train2000_20260813_v1

assert r["step"] == 4000 and r["max_steps"] == 8000

T1E. step4000 使用两张额外 GPU 并行评测 Train64 / Dev64
==========================================================

T1 成功后运行。默认 Train64 使用 GPU0、Dev64 使用 GPU6；评测与后续四卡
训练使用不同 GPU，因此可以先运行本段，再立即运行 T2，不必等评测结束。

cd /home/zjr/Tracker
set -euo pipefail

PY=/home/zjr/anaconda3/envs/reconviagen/bin/python
EVAL_GPUS=${EVAL_GPUS:-0,6}
if [ "$(awk -F, '{print NF}' <<<"${EVAL_GPUS}")" -ne 2 ]; then
  echo "blocked: EVAL_GPUS must contain exactly two GPU ids"
  exit 2
fi
IFS=, read -r TRAIN64_GPU DEV64_GPU <<<"${EVAL_GPUS}"

RUN=/data/zjr/proobjaverse_official_slat_train2000_20260813_v1
SOURCE_OUT=${RUN}/B_condition_lora_train2000_step8000_seed42_4gpu_v1
CKPT=${SOURCE_OUT}/checkpoints/step_004000.pt
TRAIN2000=${RUN}/cache_train2000_protocol2128_views8_v1
DEV64=${RUN}/cache_dev64_protocol2128_views8_v1
SS_REPORT=/data/zjr/native_no_vggt_mixed_real376_synth868_20260808_v1/ss_eval_synthetic_dev32_fixedcfg3_count125_v3/report.json
STOCK_FREEZE=/data/zjr/native_slat_genrecon_v2_mixed1k_20260802_v1/stock_slat_freeze_v2.json

test -s "${CKPT}"
test -s "${SOURCE_OUT}/stage_report_step_004000.json"

for SPEC in \
  "train64:${TRAIN64_GPU}:${TRAIN2000}" \
  "dev64:${DEV64_GPU}:${DEV64}"
do
  IFS=: read -r NAME EVAL_GPU CACHE <<<"${SPEC}"
  OUT=${RUN}/eval_${NAME}_B_scale_step4000_seed424344_v1
  LOG=${RUN}/logs/T1E_eval_${NAME}_step4000.log
  UNIT=tracker-proobj-slat-eval-${NAME}-step4000-v1
  if [ -s "${OUT}/report.json" ]; then
    echo "reuse ${NAME} step4000: ${OUT}/report.json"
  elif [ -e "${OUT}" ]; then
    echo "blocked partial ${NAME} output: ${OUT}"
    exit 2
  else
    systemd-run --user \
      --unit="${UNIT}" --collect \
      --property=WorkingDirectory=/home/zjr/Tracker \
      --property=StandardOutput=append:${LOG} \
      --property=StandardError=append:${LOG} \
      /usr/bin/env \
        CUDA_VISIBLE_DEVICES="${EVAL_GPU}" \
        HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
        ATTN_BACKEND=flash_attn SPCONV_ALGO=native \
        MPLCONFIGDIR=/tmp/matplotlib NUMBA_CACHE_DIR=/tmp/numba_cache \
        TORCH_EXTENSIONS_DIR=/tmp/torch_extensions \
        "${PY}" -u -m pose_point_depth_mv.evaluate_proobjaverse_official_slat_gt_support \
          --arm condition_lora \
          --cache_manifest "${CACHE}/slat_manifest.json" \
          --lifting_cache_manifest "${CACHE}/lifting_manifest.json" \
          --checkpoint "${CKPT}" \
          --native_ss_report "${SS_REPORT}" \
          --stock_slat_freeze "${STOCK_FREEZE}" \
          --output_dir "${OUT}" \
          --weights ema --joint_seeds 42,43,44 \
          --max_objects 64 --surface_samples 20000
    echo "started ${NAME} step4000 on GPU ${EVAL_GPU}: ${UNIT}.service"
  fi
done

echo "current terminal remains open"
