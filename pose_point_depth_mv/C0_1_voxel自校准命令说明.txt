# C0.1 Voxel-level Self-calibration 命令说明
# 日期：2026-07-17
#
# 一、为什么必须增加这一阶段
#
# V7的对象级hard margin：
#
#   sample_score(correct) - max(sample_score(training corruptions))
#
# 只能证明一个对象整体上更像correct，不能直接广播成16^3 local gate。
# C0.1改为对每个voxel独立计算：
#
#   m_hard[x] = voxel_score_correct[x]
#             - max_c voxel_score_training_corruption_c[x]
#
#   gate[x] = fixed_correct_active[x] AND (m_hard[x] > tau)
#
# tau在本轮固定为0。对象级mean/median/bootstrap只用于汇总和科学判定，
# 绝不作为gate输入，也不允许广播回16^3空间。
#
# Gate只使用训练时见过的三种control：
#   pose_cyclic1
#   depth_view_cyclic1
#   visual_view_cyclic1
#
# pose_reverse和depth_spatial仍是held-out control，只用于检验局部gate泛化，
# 不能参与gate构造或tau拟合。
# spatial_view_misaligned是额外held-out空间控制：每个view的visual+geometry
# 使用不同固定3D roll，view内配对保持，但跨view的same-voxel对应被破坏。
# 它共用correct view weight，不参与gate构造。
#
# 所有correct/control继续共用correct view weight，因此逐voxel差异不能来自
# support/active mask变化。共同置换所有view后，voxel score必须保持不变。
#
# 当前阶段不训练或加载SS Flow，不读取x_t、stock velocity和GT latent。
# 只有三个独立训练seed的train16/fresh48 voxel门全部通过，才允许进入C1。
# C1仍只做局部occupancy/decoder-logit监督，不启用Flow LoRA。
#
# 二、硬门
#
# 每份train16/fresh48报告都必须满足：
#   1. hard voxel margin的对象平衡mean > 0；
#   2. hard voxel margin的对象平衡median > 0；
#   3. hard voxel margin对象bootstrap 95% CI下界 > 0；
#   4. active voxel中hard margin > 0的平均比例 >= 60%；
#   5. 每个对象至少50% active voxel为正，达到该条件的对象比例 >= 65%；
#   6. pose_reverse和depth_spatial在完整active区域的local margin均通过；
#   7. 两个held-out control在gate内的正margin比例均 >= 65%；
#   8. spatial_view_misaligned的mean/median/CI > 0，object win >= 65%；
#   9. spatial_view_misaligned在active/gate内的正margin比例 >= 60%/65%；
#  10. hard margin空间标准差 >= 1e-4，禁止常数对象分数伪装成local map；
#  11. common-view permutation voxel max_abs_diff <= 1e-5；
#  12. train/fresh对象严格不重叠。
#
# 三、执行约定
#
# 1. 按V8.1 -> V8.2 -> V8.3执行；seed42配对PASS后才运行V8.4、V8.5。
# 2. 所有外层命令块最终exit 0，不会因科学FAIL关闭当前终端。
# 3. 真实程序状态写入*.exit_code，科学判定写入*.decision_code。
# 4. output已存在时不覆盖；完整report可复用，不完整目录记为98。
# 5. 不使用--fail_on_decision；科学FAIL只记录，不转换成外层shell失败。

# ========================================================================
# 四、进入C1的唯一准入条件
# ========================================================================
#
# 只有：
#   pose_point_depth_mv/outputs/
#     c0_1_voxel_selfcal_v2_multiseed_424344_20260717.decision_code
#
# 内容为0，才允许进入C1。
#
# 任一seed的train16或fresh48失败：停止，不得用对象级hard margin替代local gate，
# 不得调大physical scale，不得启用Flow LoRA，也不得删除2-view失败对象获得PASS。
#
# 三seed通过后，C1仅读取每个样本v2报告保存的voxel_maps/*.pt：
#   gate_mask[16,16,16]
#   hard_margin[16,16,16]              # inactive位置已显式归零
#   hardest_control_index[16,16,16]    # inactive位置为-1
#
# raw_hard_margin只用于审计，不能直接进入C1。C1启动时必须检查：
#   gate_mask[~active_mask]全为false
#   hard_margin[~active_mask]全为0
#
# C1只在gate_mask为真的voxel附近施加局部occupancy/decoder-logit监督；
# sample_hard_margin只能进入日志，不能参与gate、loss mask或spatial scale。
