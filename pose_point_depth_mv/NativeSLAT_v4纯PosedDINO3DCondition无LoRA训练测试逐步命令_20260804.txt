Native-SLat v4：纯 GenReCon posed-DINO 3D condition、完全无 SLat LoRA
======================================================================

目标结构：

  Native SS step2000 EMA coordinates
    -> frozen released Stock-SLat Flow
       （原版 self-attention / cross-attention / 多视图算术平均全部冻结）
    -> posed-DINO frustum projection at active 32^3 coordinates
    -> GenReCon mean/variance learned aggregator
    -> 24 个 block 前各自的 zero-init condition projection
    -> frozen Mesh decoder

唯一可训练参数：

  aggregator.*
  block_condition.*

明确不存在：PEFT、SLat attention LoRA、view-fusion gate/scorer、可训练 decoder、
Direct-SLat residual bound / wrong-support / rollout auxiliary。

下面每个 C 段都可以单独复制。长训与评估默认交给 user-systemd，因此终端可以关闭。

结果边界
========

1. Stock = Native SS step2000 EMA coordinates + 冻结的 released Stock-SLat。
2. Full = 同一坐标、同一初始噪声、同一 sampler + posed-DINO 3D condition。
3. Full 没有任何 SLat attention LoRA，也没有 v3 view gate/scorer。
4. Stock block 内原版多视图算术平均保持冻结，因此本实验回答的是：
   “只增加 GenReCon 式 3D condition 是否能改善 frozen Stock-SLat”，
   而不是“彻底删除 Stock 原版 cross-attention 平均是否更好”。
5. val6 是开发诊断，不能形成正式 science claim。
