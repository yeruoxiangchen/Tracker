# N0-N4 Neighborhood-aware Lifting训练测试命令（2026-07-18）

# ======================================================================
# 当前模型结构与本轮唯一变量
# ======================================================================
#
# 冻结：
#   VGGT / DINO image encoder / ReconViaGen bridge / SS Flow / decoder / SLAT
#   Flow LoRA始终关闭。
#
# 输入：
#   每个view保留独立的visual patch、ray/pose、depth residual、depth confidence；
#   在canonical 16^3上形成[V,4096,C]，不提前丢失view identity。
#
# C0.3空间协议：
#   exact evidence
#     -> correct-derived fixed support
#     -> 对correct和全部pose/depth/visual controls统一执行
#        support-normalized [1,2,1]^3 aggregation
#     -> frozen-support same-voxel pair head
#     -> voxel hard margin = correct - max(training controls)
#
# [1,2,1]^3与“对8个半voxel偏移做三线性采样再平均”等价。因此本轮
# gaussian3就是固定trilinear half-voxel tolerance，不再另造一个数学同构的
# trilinear实验。N2比较exact与这一neighborhood协议，并做core/shell分解。
#
# C1输出两类权重，但N3正式协议不变：
#   hard_admitted_soft_weight
#     = tanh(relu(hard_margin)/0.25) * raw_reliability
#     non-positive margin严格为0，是N3通过后允许使用的正式权重。
#   continuous_soft_weight
#     = 0.10 * sigmoid(hard_margin/0.25) * raw_reliability
#     active负margin仍保留低幅权重，只用于C1因果消融。
# 二者都不是概率；inactive严格为0，raw hard margin禁止直接作为C1 scale。
#
# V12.5及以后统一在前台直接运行子Bash，进展实时输出到当前终端，脚本内部tee
# 同时保存日志。不使用nohup、后台&或专门监视命令。子脚本的exit只结束
# `/bin/bash script.sh`子进程，不会关闭当前交互终端。
