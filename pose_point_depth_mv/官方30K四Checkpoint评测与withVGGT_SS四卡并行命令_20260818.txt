二、30K 四 checkpoint 实际测什么
======================================================================

每个 checkpoint 有三次四卡 GPU wave，随后一次 CPU 聚合：

1. `train64_gt`

   - official GT support；
   - no-VGGT Stock SLat vs 30K trained no-VGGT SLat；
   - 4 个 shard，每卡 16 个对象；
   - 回答旧 Train64 上的拟合兼容表现。

2. `legacy_dev64_gt_training_overlap`

   - official GT support；
   - no-VGGT Stock SLat vs 30K trained no-VGGT SLat；
   - 4 个 shard，每卡 16 个对象。

3. `legacy_dev48_predicted_training_overlap`

   - official no-VGGT Native-SS step2000 EMA/CFG5 产生 predicted support；
   - A = posed-DINO interface -> Stock SS -> no-VGGT Stock SLat；
   - B = posed-DINO -> official Native-SS step2000 -> no-VGGT Stock SLat；
   - C = posed-DINO -> official Native-SS step2000 -> 当前 30K SLat checkpoint；
   - 4 个 shard，每卡 12 个对象；
   - 保留 A/B/C、B-A、C-B、C-A。

三、非常重要的科学边界
======================================================================

checkpoint 的 29,861 个训练 UID。
