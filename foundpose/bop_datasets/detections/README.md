
# Default detections/segmentations for Task 4 of BOP Challenge 2023

The default detections/segmentations are results of CNOS (https://github.com/nv-nguyen/cnos), a strong baseline for CAD-based novel object segmentation prepared by Van Nguyen Nguyen et al. (https://nv-nguyen.github.io/) for Tasks 5 and 6 of BOP Challenge 2023.

Below is a list of files with 2D detections/segmentations for the seven core datasets together will URLs of the corresponding submissions.
